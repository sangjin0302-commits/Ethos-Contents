# 웹사이트 블로그 MD 예시 — 공인중개사 업무정지

`docs/website-md-spec.md`대로 만든 국문·영문 두 파일이다. ChatGPT 통합 테스트의 블로그 원고(법령·재결례 2026-10-06 원문 대조)를 바탕으로 했다. **발행 전 사용자 승인 필요.**

관리자 페이지에 올리는 법:
1. 블로그 글 새로 만들기 → 머리말의 `slug`, `title`, `excerpt`, `category`, `tags`를 각 칸에 입력
2. `---` 아래 본문 전체를 "본문 (Markdown)" 칸에 붙여 넣기
3. 영문 칸(`titleEn`, `excerptEn`, `tagsEn`, 영문 본문)도 `website.en.md`에서 같은 방식으로 입력
