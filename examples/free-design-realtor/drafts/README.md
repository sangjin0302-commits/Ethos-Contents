# 세 방향 시안 (예시)

표지와 본문 한 장을 세 방향으로 만들어 비교한 예시다. `python scripts/preview_drafts.py <drafts 폴더>`가 `drafts-sheet.png`(위에서부터 A·B·C)를 만든다. 시안은 QA 게이트를 거치지 않고, 고른 방향으로 전체 세트를 만든 뒤 `qa_render.py`로 검사한다.

- A: 브랜드 세리프 제목 + Pretendard 본문 (시범 세트 채택)
- B: 제목까지 Pretendard 800, 굵은 타이포
- C: 모든 카드 크림 바탕 여백형, 상자 대신 선
