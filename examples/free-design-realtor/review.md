# 2026-10-06 카드 디자인·문체 개선 검토

## 반영

- 표지 부제·약속·그림을 중앙 묶음으로 배치. 제목과 본문 텍스트는 왼쪽 정렬 유지.
- 비교 항목의 flex:1·space-evenly 제거. 관련 요소를 일정 간격으로 모음.
- 오른쪽으로 떨어져 있던 보조 아이콘을 왼쪽 기준선에 연결. 108px에서 88px로 줄임.
- 텍스트 실제 경계로 본문 중심 편차와 위·아래 여백을 측정. 강제 가운데 정렬이나 발행 차단은 하지 않음.
- 시범 카드 5·8번의 가운뎃점 나열을 문장 연결로 수정. JSON과 HTML 동시 변경, 숫자·조건·판단 범위 유지.
- 영업정지 블로그의 중복된 '먼저'와 인용 뒤 조사 줄바꿈 두 곳 수정. 남은 '출처 입력'은 출처를 확인한 척 삭제하지 않음.
- 확인된 결론 우선, 근거 없는 양시론·양비론 지양을 공통 지침과 프로젝트 지침에 반영.
- 숫자 없는 표지 promise 허용, 문형·어미 비율 권고화. Kiwi 문장 분리·국문 캡션 검사·Vale 편집 규칙 활용.
- 카드 윤문에 원문 근거·앞뒤 메시지 제공. 블로그·SNS 문단 제안 CLI 추가. 변경률 30% 통일, 카드 적용 시 승인·검수 상태 초기화.
