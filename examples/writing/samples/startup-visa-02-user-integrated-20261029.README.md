## 선택적으로 따라갈 요소

1. OASIS 수료증을 가지고도 다음 서류가 막막한 독자의 질문으로 시작하고, 현재 체류자격·신청경로부터 확인한다는 답을 일찍 준다.
2. 가정한 제임스와 AI 재고관리 프로그램 하나로 교육 신청서·학위자료·기술창업계획서·시제품·체류자료를 연결한다. 각 절에서 가상의 상황을 반복 소개하지 않는다.
3. '매장 재고관리 프로그램'과 'AI 자동발주 솔루션' 사이에서 단순 명칭 변경과 실제 개발 내용 변경을 구분해 설명한다.
4. 시제품에 이미 구현된 재고·판매량 분석 기능과 아직 개발 중인 자동발주 추천 기능을 한 계획서 예문에서 구분한다. 완성하지 않은 기능을 실적으로 주장하지 않는다.
5. 여권 영문 이름, 수료·학위 취득·체류기한의 각 날짜, 개인의 주거지와 회사의 사무실처럼 문서마다 무엇을 확인해야 하는지 보여 준다.
6. 후반부에서 직접 준비할 자료, 무료 사전 검토로 먼저 확인할 사항, 별도의 유료 행정서류 작성·법령상 허용되는 제출 업무를 **한 번** 안내한다.
7. 과거 수정 과정에서 도입이 지나치게 길어졌다는 사용자 피드백을 반영한 사례다. '자세함'을 문단 수나 글자 수의 증가로 오해하지 않는다.

## 읽기용 편집 및 출처 보호

- `.source.txt`는 업로드 파일의 원래 문자·개행·마크다운·붙여넣기 잔여물을 보존한다.
- `.md`는 NBSP 특수 공백, `&#x20;`, 과도한 빈 줄·끝 공백을 정리하고 독립적으로 굵게 표시된 소제목을 `##`로 표시했다.
- 원고의 `출처 입력` 2곳을 제거하고 3줄 요약의 `1\.` 등 번호 이스케이프, 첫 태그의 `\#`를 읽기 좋게 정리했다. 본문 내용의 법률 요건·수치·주장에 대한 수정은 하지 않았다.
- 업로드본에 정식 제목 행이 없고 본문의 `**` 강조 및 기존 네이버 상담 이미지 삽입 자리가 남아 있으므로 **이 파일을 그대로 발행하지 않는다**. 발행 형식은 최신 `docs/blog-authoring-spec.md`를 따른다.

## 법률·업무범위 관련 미확인 및 발행 차단 사유

- 업로드본의 **OASIS 교육 수료 후 3년 경과 시 D-10-2 변경 제한·교육 재이수 중 예외**는 과거 공개 안내에 나타나지만, 2026-10-19자 법무부 체류민원 매뉴얼의 첨부 전문과 직접 대조하지 못했다. 현행 규칙이라고 단정하거나 다른 글에서 복사하지 않는다.
- 교육부의 국내 D-2 기술창업 변경 안내는 특허·실용신안·디자인 증빙을 기존 검토에서 **'해당자'** 제출자료로 표시했으나, 이번 업로드본의 특허 절은 해당 한정어 없이 '제출자료'로만 서술한다. 발행 전 공식 원문과 대조해 정확한 대상·조건을 보존해야 한다.
- 국내 전문학사·졸업예정자, '학위증명서 또는 추천서'의 인정 기관/추천 요건, 국내 변경·해외 사증신청의 경로별 목록도 최신 법무부 개별 지침과 최종 대조해야 한다.
- 제임스와 시제품·스마트리테일 주식회사는 설명용 설정이다. 실제 의뢰인·고객·상담·수임·허가 사례로 소개하지 않는다.
- 행정사의 서류작성·제출 업무는 법령상 허용되는 범위에 한한다. 특허출원 대리·법인 등기와 분리하며 체류자격 허가를 약속하지 않는다.
- 발행 원고의 공식 법령·기관 안내 확인일·판본은 관련 `research/`와 검수 기록에 따로 남긴다. 검수 완료 전 기존 콘텐츠·카드·SNS·웹사이트의 승인 원본을 대체하지 않는다.
