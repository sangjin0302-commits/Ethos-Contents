## 선택적으로 따라 쓸 내용

1. **도입에서 서로 다른 결론을 먼저 제시한다.** 청소년 주류 제공 부산 재결의 영업정지 2개월 → 15일, 서울 재결의 기소유예를 이미 반영한 1개월 유지라는 대비가 독자의 질문을 만든다. 과거 사건의 숫자를 현행 기준으로 옮기지 않고 2024년 이후 처분기준을 별도 소개한다.
2. **실제 재결의 설명 주체를 구분한다.** 부산 사건에서 영업자 측의 ‘청소년이 뒤늦게 합류했다’는 설명은 주장으로, 신분증 확인 없이 주류를 제공했다는 사실은 재결기관의 인정으로 기술한다. 상담 사례나 성공실적을 창작하지 않는다.
3. **결론을 가른 자료와 날짜를 보여 준다.** 동일 위반 전력, 사전통지·의견제출·처분일, 기소유예가 이미 반영된 여부, 위반일과 재적발일·이전 처분일의 선후관계를 구체적으로 설명한다. 대법원 2014두2157 언급은 판결 당시 사실로만 사용하고 새로운 사건에 날짜·처분량을 복제하지 않는다.
4. **면제·감경·과징금을 별도의 법적 경로로 설명한다.** 신분증 위조·변조·도용 등 처분 면제 요건, 위반 정도와 기소유예 등 감경 요건, 과징금 전환의 제외사유와 산정기준을 섞지 않는다. 법률상 ‘면제한다’, ‘경감할 수 있다’, ‘과징금을 부과할 수 있다’의 법적 효과와 재량은 서로 다르다.
5. **소비기한 하루 경과 라면 3개 사건을 자료 대조로 연결한다.** 조리·판매 목적의 보관과 실제 사용을 구별하고, 15일 → 7일이라는 재결과 서울시가 건의한 ‘소비기한의 10% 이내’ 규정 제안도 구별한다. 입법 건의를 시행 중 규정으로 소개하지 않는다.
6. **독자가 가진 서류를 실제 작업으로 잇는다.** 사전통지서와 CCTV·주문·결제기록의 시각·인물·행위가 어떤 부분에서 일치하는지, 형사사건 처리결과와 과거 처분서의 어떤 항목을 의견서에 반영할지 구체적으로 쓴다. 영상·진술·서면이 각각 무엇을 증명하는지 구분한다.
7. **전환 문구는 마지막에 한 번 배치한다.** 독자가 보낼 통지서·증빙자료·이전 처분내역을 제시하고, 무료 사전 검토는 우선 확인할 절차·법령·자료의 방향 안내로 제한한다. 상세 증빙 대조, 의견서 작성과 법령상 가능한 제출은 범위·비용을 따로 확인하는 업무로 구분한다.

## 정리본 편집 범위

- 사용자가 붙여 넣은 본문은 네이버 편집기에서 제목이 별도 입력된 형태다. 정리본 맨 앞에는 기존 시리즈 목차에서 확인되는 정식 제목을 **참고용으로 보완**했으며 사용자 원문에 제목이 원래 있었다고 표시하지 않는다.
- 원문의 10개 본문 절과 20개 하위 문단 제목을 Markdown 제목으로 구분했다. 원문 문장을 원칙적으로 유지하며, 소제목·출처·사례가 서로 붙어 보이지 않도록 줄 간격만 정리했다.
- 원문의 네이버 편집기 잔여 표식 `출처 입력` 3곳, `AI 활용 설정` 2곳, `사진 설명을 입력하세요.` 1곳은 정리본에서 제거했다. 사진 클릭 안내는 **기존 상담 이미지 4개 자리표시**로 옮겼으며 실제 이미지 파일이나 링크를 새로 만들거나 확인하지 않았다.
- 복사 과정의 특수 공백은 일반 공백으로 통일했다. 단순 오탈자 `작업울`·`관련있습니다`를 수정하고 ‘행정심판 관련 업무’를 행정사법상 대리권처럼 읽지 않도록 법령상 허용 범위의 업무라고 정리했다.
- 원문의 태그 **22개** 중 본문과 직접 관련성이 낮거나 중복된 `#행정처분`, `#주류판매적발`을 정리본에서 제외해 **20개**로 맞췄다. 사용자 추가 브랜드 태그 `#행정사지상진`과 `#에토스행정사사무소`는 보존했다. 원문 보존본은 22개 그대로 둔다.
- 법조항·재결·숫자·조건을 최신 판본으로 전면 교정하거나 실제 사건의 사실관계를 재판단하지 않았다. 정리본을 근거 자료나 발행 완성본으로 바로 사용하지 않는다.

## 다른 글에 그대로 복제하지 않을 내용

- **5만 자가 넘는 분량은 기본 집필 분량이 아니다.** 실제 비교·절차·문서 확인을 풀어 쓰는 방식만 참고하고, 같은 뜻의 설명이 반복되면 통합한다. 특히 9절의 증거대조와 10절의 업무 안내, 재결 결과의 여러 차례 반복은 기계적으로 본뜨지 않는다.
- 원고의 2008·2009·2010·2014·2024년 실제 사건, 판결번호, 조문·별표의 현재 적용 범위, 소비기한 및 과징금 산정 내용은 각 새 글에서 공식 원문과 시행판본을 재확인한다. 여기의 숫자를 다른 업종·사건에 가져다 쓰지 않는다.
- 기존 사전통지 단계와 최종 처분 뒤의 불복 단계, 행정사법상 행정문서 작성·제출과 법정 대리권이 필요한 행정심판·소송 업무를 혼동하지 않는다.
- 원문의 실제 상담 이미지 4장과 대상 URL은 이번 작업에서 확인되지 않았다. 정리본의 자리표시는 이미지와 연결이 설정됐다는 의미가 아니다.
- SEO 검색량·문의·수임 성과를 확인하지 않았다. 이 예시는 **문체·설명 설계 예시**이며 성과 검증 자료가 아니다.
