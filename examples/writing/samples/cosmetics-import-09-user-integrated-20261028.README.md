# 화장품 인허가 ⑨ — 사용자 편집 통합본 참고 범위

- 등록: 2026-10-28. 사용자 업로드 `붙여넣은 마크다운.md`.
- 출처: 기존 AI 작성 원고와 다수의 단락별 윤문안을 사용자가 검토·선택·수정·통합한 원고. 순수한 사용자 단독 작성으로 표시하지 않는다.
- [읽기용 정리본](cosmetics-import-09-user-integrated-20261028.md) · [원문 그대로](cosmetics-import-09-user-integrated-20261028.source.txt)
- 상태: **긍정적인 문체·전개·문서 대조 예시**. 법률 검증 완료, 실제 고객/상담/수임 사례, 발행 승인, 카드 Source Lock, 마케팅 실적 인증이 아니다.

## 이 예시에서 선택적으로 참고할 요소

1. **실제 사업자의 견적서 질문에서 시작**: 국내 OEM 크림을 판매하던 브랜드 사업자가 해외 세럼을 발주하며 생산단가·납기는 확인했지만 한국 수입용 증명서를 받을 수 있는지 놓친 상황을 중심 질문으로 삼는다.
2. **문서의 실제 항목을 대조**: 사업자등록증과 책임판매업 등록필증의 차이, 견적서 내부 코드·제조증명서 영문 제품명·실제 용기의 이름, 제조회사·실제 생산공장, 원료명·배합량을 비교한다. '서류 정합성 검토' 같은 추상어로 끝내지 않는다.
3. **조건이 달라지면 판단도 달라짐을 보여 줌**: 첫 수입과 같은 품목 재수입, 원료 변경과 용량 30mL→50mL 추가의 차이, 품목코드와 원료목록코드의 역할을 같은 세럼 사례로 풀어 쓴다. 실제 처리 요건은 새 글의 공식 근거로 재확인한다.
4. **제조번호 A001·A002로 품질관리 설명**: 시험성적서의 제조번호, 입고 수량과 판매처별 기록을 함께 보여 줘 검사 자료가 어떤 생산분을 입증하는지 설명한다. 법정 검사 면제는 별도 조건이다.
5. **독자 스스로 확인할 자료와 행정사 업무의 구분**: 해외 공장에 요청할 자료, 등록 유형 변경 신청서의 기재사항, 표준통관예정보고에 필요한 제품정보를 구분하고 관세·품질시험의 전문업무는 별도 범위로 다룬다. 후반부에서 기존 등록필증·제조/판매증명서·최종 원료정보를 보내는 무료 사전 검토를 안내한다.

## 읽기용 정리 내역

- `.source.txt`는 업로드 텍스트의 문자·개행·이스케이프를 손대지 않고 보존한다.
- `.md`는 NBSP 특수 공백을 일반 공백으로, `&#x20;`를 제거했고, 연속 빈 줄·불필요한 줄 끝 공백만 정리했다.
- 기존 독립 강조 제목을 Markdown `##`/`###` 계층으로 정리하고 말미 `3줄 요약` 제목을 표시했다. 1~3번 요약의 이스케이프와 마지막 첫 태그의 역슬래시를 제거했다.
- 이 처리는 표시용 편집이며 원고의 법률 판단·조문·숫자·인물·서술 내용을 임의로 추가하거나 삭제하지 않았다.

## 원고 그대로 모방하지 않을 부분

- 사용자 첨부본에는 **발행용 정식 제목 행이 없고**, 시리즈 소개가 목차 앞에 있다. 실제 블로그 발행 시 최신 `docs/blog-authoring-spec.md`의 제목·인사·도입·목차·공통문장 순서를 확인한다.
- **원고가 길다는 사실 자체는 문제가 아니다.** 다만 같은 제조증명서·판매증명서 설명과 민수 씨를 다시 소개하는 문단이 여러 절에 있어, 다른 글에서는 각 문단이 새 판단·자료를 추가하는지 보고 중복을 덜어 낸다.
- 원본의 특수 공백, `&#x20;`, `1\\.`·`\\#` 이스케이프와 상담 이미지 자리표시 등 붙여넣기 흔적은 모범 문체가 아니다. 실제 이미지와 연결 주소는 별도 확인 대상이다.
- **CTA 보완 필요**: 업로드 원고에는 보낼 자료·무료 사전 검토 내용은 있지만, **별도 유료 행정서류 작성·제출 업무의 범위와 비용 협의**가 명시된 최종 문단이 없다. 발행용 글에서는 무료/유료 구분을 복원하고 승인되지 않은 상품·성과를 만들지 않는다.
- 「화장품법」 제4·8·10조·시행령 제2조·시행규칙 제5·12·13·19조, 제조·판매증명서 원본 제출, 표준통관예정보고·품목코드·원료목록코드, 품질검사 면제, 행정사/관세사 업무 경계는 **실제 발행 전 현행 법령·협회 운영자료로 독립 검증**한다. 이 예시 등록에서 법령 확인·Solar 실행·자동 Prose hints 통과를 새로 주장하지 않는다.
- 민수 씨와 해외 세럼, A001/A002 및 용량 비교는 **설명용 상황**이며 실제 수임사건·성과로 소개하지 않는다. 검색·문의·수임 효과도 미검증이다.

## 적용 범위

독자의 사업상황 → 실제 서류의 어떤 항목이 다른지 → 조건에 따른 판단 변화 → 지금 확인할 자료 → 법령상 가능한 행정서류 작성 업무로 연결하는 **설명 방식만** 참고한다. 이 원고를 승인 콘텐츠나 `content/`의 Source Lock에 복사하지 않고, 새 글에서 공식 법률 근거와 서비스 범위를 따로 확인한다.
