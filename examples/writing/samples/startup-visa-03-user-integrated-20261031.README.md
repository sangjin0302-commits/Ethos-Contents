## 선택해서 활용할 긍정 요소

1. AI 재고관리 프로그램을 시연하던 제임스에게 매장 사장이 월 이용료를 제안하는 상황으로 독자의 질문을 만든다.
2. 노트북 시연과 실제 재고·발주에 사용하는 운영을 대비하고, 화면 캡처와 개발기록에서 무엇을 볼지 적는다.
3. 무료 베타테스트·테스트비·실비·정식 이용계약에서 문서의 제목보다 **프로그램 이용, 지급 목적, 서비스 개시일, 지속 기술지원**을 살핀다.
4. 법인명의 계약·회사통장과 창업자 개인의 영업·설치·운영 활동을 분리해 설명한다.
5. 계약서의 예정일, 매장의 실제 사용일, 입금일이 다를 때 어떤 자료를 비교할지 보여 준다.
6. 결말에서 체류자료·개발현황·제안서를 연결하고, 무료 사전 검토와 별도 위임범위의 행정문서 작성·제출을 구분한다.

## 보호해야 할 사실·표현

- 제임스, 스마트리테일 주식회사와 매장·대화·날짜·계약 문구는 **설명용 가상 상황**이다. 실제 에토스 고객·수임 또는 결과로 쓰지 않는다.
- ‘출처 입력’, NBSP, `&#x20;`, `\#` 등 붙여넣기 표식은 문체 사례가 아니다. 원문은 별도로 보존한다.
- 한국생산성본부 글로벌창업이민센터의 D-10-2 영리활동 제한 안내는 확인했지만, 개별 무료 테스트·실비 정산·계약 체결 자체의 세부 허용 여부는 최신 법무부 체류지침의 직접 대조가 남아 있다.
- 대법원 2015두48846은 체류자격 변경허가의 성격과 재량을 다룬 판결이며 D-10-2 제품 판매 사건이 아니다.
