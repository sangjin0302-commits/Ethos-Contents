# 카드뉴스 채널별 패키징

하나의 승인된 원문과 공통 card-data를 사용하되, 채널마다 같은 파일 묶음을 그대로 복사하지 않는다. 사실·한정어·카드 순서는 언어별 Source Lock을 지키고, 출력 범위와 캡션만 채널에 맞게 조정한다.

## Instagram

- 기본 출력은 4:5, 1080×1350 전체 캐러셀이다.
- 표지에서 대상과 문제를 2초 안에 알리고 2~3장 안에 실용적 보상을 준다.
- 캡션은 카드 내용을 다시 전부 요약하지 않고 대상 독자, 추가 맥락, 검토 경계만 보충한다.
- 프로필 방문과 무료 검토가 목표여도 카드 안에 연락처·URL·버튼을 넣지 않는다.

## LinkedIn

- B2B 독자가 판단할 수 있도록 문서 포스트 또는 PDF 패키지를 우선 검토한다.
- 영문은 국문 직역이 아니라 같은 사실 구조를 보존한 독립 편집본으로 쓴다.
- 첫 페이지, 페이지 순서, 글꼴 포함 여부와 모바일 미리보기를 확인한다.
- 캡션은 대상 독자와 실무적 판단 문제를 분명히 하고 과장된 thought leadership 문구를 만들지 않는다.

## 카카오

- 전체 캐러셀이 필요하지 않으면 대표 카드 1장이나 짧은 묶음으로 파생한다.
- 작은 미리보기에서도 제목이 읽혀야 한다.
- 카카오 글 본문과 카드가 같은 설명을 반복하지 않게 역할을 나눈다.

## 블로그·홈페이지

- 비교·절차·체크리스트처럼 본문 이해를 돕는 카드만 삽입한다.
- 카드만 보아도 맥락이 끊기지 않도록 짧은 제목이나 설명을 둔다.
- alt text는 장식 설명이 아니라 카드의 핵심 판단 내용을 적는다. Instagram 캐러셀은 카드별로 1개씩 작성하고 distribution.md에서 1부터 카드 수까지 연속 번호를 붙인다. alt text에는 무료 검토·문의·DM 같은 영업 CTA를 넣지 않는다.
- 이미지가 본문을 그대로 복제하면 사용하지 않는다.

외부 사진·아이콘·일러스트를 사용하면 같은 콘텐츠 폴더의 assets.md에 원본 URL, 제작자, 라이선스, 확인일, 수정 여부를 기록한다. 발행 전 scripts/validate_distribution.py로 alt text와 자산 기록을 확인한다. 외부 자산을 사용하지 않았으면 EXTERNAL ASSETS: No를 명시한다.

## 아랍어 및 추가 언어

- 번역 전에 공식 용어와 원문 의미를 잠근다.
- 아랍어는 RTL 조판과 승인된 로컬 폰트를 별도로 검수한다.
- 실제로 제공하지 않는 번역·확인 업무를 CTA에서 암시하지 않는다.

## 선택 원칙

모든 채널 패키지를 매번 만들 필요는 없다. 대상 독자와 운영 목적이 확인된 채널만 출력한다. 새 채널은 계정 목적, 독자, 비율, 캡션, CTA 경로, 측정항목을 정한 뒤 추가한다.
