# 카드뉴스 제작 시스템 품질 감사 — 2026-10-29

## 범위와 Source Lock

최신 `main`에서 제작 명세, 디자인 가이드, 자동 디자인·빌드·CI·QA·리뷰·스모크 코드를 확인했다. 승인 대표 세트는 `GAME-OVERSEAS-06`, `SUSPENSION-SURCHARGE-04`, `TEST-SUSPENSION-V3`이며 국·영문 축소 시트와 주요 원본 PNG를 직접 검토했다. `STARTUP-VISA-02-PROSE-REVIEW`는 법률 검증·승인 전이므로 검증 자료에서 제외했다. 승인 원고와 발행 상태는 변경하지 않았다.

## 실제 이미지에서 확인한 문제

- `GAME-OVERSEAS-06`은 Golden 기준선으로 유지한다. 다만 EN 2·5번은 네 줄 제목이 본문 공간을 크게 차지하고, EN 10번은 우측 열이 상대적으로 조밀하다. KO 6번의 동일 크기 3박스는 의미 위계가 약하다.
- `TEST-SUSPENSION-V3`는 아이콘·막대·인용·타임라인·CTA가 섞여 회귀 세트로 적합하다. EN 10번은 세 패널과 하단 CTA 사이 여유가 타이트하지만 하드 오버플로는 없었다.
- `SUSPENSION-SURCHARGE-04` 5번은 제목이 “이 순서로 / in this order”인데 2×2 박스가 방향을 표현하지 못했다. KO·EN 모두 번호가 있어도 읽는 경로가 좌우·상하로 갈려 결정 흐름이 약했다.
- 추가 비교 세트의 영문 시트에서는 긴 제목·주석이 표 또는 본문과 가까워지는 사례가 있었다. 이는 현재 오버플로 게이트 통과와 실제 시각 완성도가 같은 뜻이 아님을 보여준다.

## 코드 개선

1. `auto_design.component_plan()`은 세 장 연속만 피하던 로직에 비연속 과반과 A-B-A-B 교대 편중 회피를 추가했다. 의미상 후보가 하나뿐이면 바꾸지 않고, 후보 순위와 사용 횟수만 사용해 언어별 카피 길이에 따른 한·영 불일치를 만들지 않는다.
2. `design_review.review()`은 표지·CTA를 첫 장·마지막 장으로 가정하지 않고 `data-card-type`으로 판별한다. 부분 렌더나 CTA 없는 세트에서도 본문 검사가 빠지지 않는다.
3. 동일 구조의 비연속 과반과 A-B-A-B 반복을 `layout-repeat` 권고로 탐지한다. 자동 실패가 아니라 실제 시트 판단을 돕는 권고로 유지했다.

## 남은 위험

- `visual_regression.py`는 레거시 빌더 중심이어서 자동 디자인 전체의 픽셀 기준선을 아직 보호하지 않는다. 기준 이미지 갱신 비용과 OS별 폰트 차이를 정리한 뒤 별도 변경이 적절하다.
- `qa_render.py`는 중첩 패널의 `overflow:hidden` 잘림과 CSS `background-image` 로딩 실패를 완전히 검사하지 않는다. 실제 재현 fixture와 오탐 한계를 먼저 확정해야 한다.
- 자동 반복 경고는 미감 판단을 대체하지 않는다. 같은 구조가 비교 이해에 필요한 세트는 경고 후 유지할 수 있다.
