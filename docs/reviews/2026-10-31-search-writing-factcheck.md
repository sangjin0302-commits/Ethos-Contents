# 블로그 수익 후기 검증과 글쓰기 지침 반영 기록

확인일: 2026-10-31. 사용자 요청: 제공된 익명 게시물 이미지의 진위를 판단하고, 타당한 부분을 ETHOS 글쓰기 지침에 반영.

## 결론

수익 사례의 진위는 확인되지 않았다. 제공 이미지에는 블로그 주소, 방문자의 집계 단위·기간, 광고 승인/게재 시점, 수익 금액, 전후 분석 원자료가 없다. 이번 공개 웹 검색에서도 해당 주장을 독립적으로 확인할 원문과 당사자 데이터를 확보하지 못했다. 따라서 거짓으로 단정하지도, 재현 가능한 성공 사례로 인증하지도 않는다. 첫 예상 수익·실제 지급·제작비를 뺀 순이익은 별개이며 시간상 앞뒤만으로 프롬프트의 인과 효과가 증명되지 않는다.

| 주장 | 판정 | 반영 |
|---|---|---|
| 역할을 상위 1% 수익형 블로거로 바꾸면 성과가 난다 | 효과 보장 근거 없음 | 역할 인증 대신 독자·근거·목표·금지사항 명시 |
| 상위 글의 제목·도입·본문·마무리를 분석한다 | 편집 방법으로 조건부 타당, 순위 인과 증거 아님 | 실제 검색/본문 확인, 부족한 답 탐색, 복제 금지 |
| 방문자가 많은 글과 돈 버는 글은 다를 수 있다 | 광고 수입의 다변수 구조와 부합 | 소유자 실제 데이터로만 수익 비교, ETHOS는 적합 문의 중심 |
| 일상·후기를 비교·문제 해결형으로 바꾼다 | 독자 목적에 맞을 때 타당 | 원문 근거로 추가 가치, 모든 후기/일상을 저품질로 취급하지 않음 |
| 고단가 키워드로 넓힌다 | 조건부이며 지표 혼동 위험 | 광고주 입찰가와 게시자 RPM 구분, 무관 주제 확장 금지 |
| AI가 검색엔진의 저품질 판정을 찾아 고친다 | 공식 판정 능력처럼 말하면 부정확 | 관찰 가능한 결함·설정·소유자 데이터로 분리 진단 |

공식 근거와 적용 절차는 `docs/search-intent-writing.md`의 출처 1~10과 해당 절에 있다. 이미지의 작성자 정보와 원본 캡처는 저장소에 복제하지 않는다.

## 변경 기록

- `docs/search-intent-writing.md`: 검증된 원칙, 실제 검색 관찰, 문제 해결형 편집, 역할별 성과 측정, 저품질 단정 금지, 공식 출처를 추가.
- `MANIFEST.md`: Active 블로그 보완 지침으로 등록하고 기본 적용 범위를 요약.
- `AGENTS.md`, `CLAUDE.md`: 새 블로그·홈페이지 집필에서 기본 요약을 사용하고 실제 검색 분석 요청에서 상세 문서를 읽도록 연결.
- `.agents/skills/ethos-editorial/SKILL.md`: 기존 편집 단계에 검색 의도·추가 가치·데이터 한계를 연결. 별도 도구 연쇄 실행이나 새 점수 게이트 없음.
- `tests/test_search_intent_writing.py`: 진입점 연결, 출처, Source Lock·채널 보호와 수익/제재 단정 방지 문구의 문서 회귀 검사.

기존 승인 `content/`, 고정된 블로그·웹사이트·카드 명세, `state/design-freeze.json`, 카드 렌더러·브랜드·수치·스키마, 원본 서브모듈, 의존성·자동화 설정은 변경하지 않는다. 기존 변경 이력은 보존하며 이번 검증의 상세 기록은 이 문서와 PR에 남긴다.

## 검증의 한계

문서 회귀 검사와 CI 성공은 지침 연결·저장소 무결성 검사다. 실제 글의 법률적 정확성, 순위, 광고 수익, 문의 증가, 원래 수익 후기의 진위를 입증하지 않는다. 실제 채널 데이터가 없는 성과는 미측정 상태다.
