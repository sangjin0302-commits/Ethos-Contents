# ETHOS 홈페이지 비주얼 디자인 시스템 — 확장안 v1.0

상태: **제안 / 미승인** · 작성일: 2026-10-12
적용 대상: ethosattorney.com의 비주얼 및 향후 홈페이지용 자체 일러스트.
비적용 대상: 기존 승인 카드뉴스 세트의 `card-data`, `design.css`, `ko/`, `en/`, `out/` 및 제작·QA 규칙. 이 문서는 해당 자산을 바꾸지 않는다.

## 1. 정체성

**ETHOS — Complex Paths, Clear Decisions.**

인허가·비자·사업 진입 절차의 여러 갈래를 명확한 판단과 실행 순서로 정리하는 사무소. 이를 표현하는 대표 시각 언어는 **경로(path), 연결(bridge), 단계(layers), 문턱·진입(arch)** 이다.

- 성격: 차분함, 분석적, 신뢰 중심, 현대적, 국제적, 실제 판단과 절차 중심.
- 표현: 프리미엄 미니멀 에디토리얼 + 절제된 건축적 그래픽.
- 피할 것: 애니메이션풍 캐릭터, 과장된 표정, 스톡 악수/회의 장면, 법전·판사봉의 무의미한 반복, 과도한 3D, AI 이미지에 들어간 문자.
- 생성된 건축 일러스트는 **브랜드를 설명하는 개념적 그래픽**이다. 실제 사무실·사업장·고객·사건을 묘사한 것처럼 사용하지 않는다.

## 2. 원본과 우선순위

1. 브랜드 토큰의 정본: `brand/tokens.json` v1.1. `brand/tokens.css`는 같은 값을 유지한다. 변경은 승인 후에만.
2. 카드 제작·프레임·타이포·렌더: `docs/card-authoring-spec.md`, `docs/card-design-guide.md`가 우선한다.
3. 이미지 이용·출처: `docs/asset-policy.md`가 우선한다.
4. 브랜드 철학: `docs/brand-philosophy.md`를 따른다.
5. **실제 웹사이트 컴포넌트·운영 정책은 웹사이트 저장소가 우선**한다. 이 문서만으로 웹사이트 코드나 기존 CSS를 변경하지 않는다.

## 3. 색상 — 기존 자산 그대로 재사용

| 역할 | 기존 토큰 | 값 | 권장 용도 |
|---|---|---|---|
| 핵심 브랜드 | `navy` | `#1B2B6B` | 건축적 주 구조·제목·선명한 강조 |
| 진한 브랜드 | `navyDeep` | `#152056` | 네이비 배경·강한 대비 |
| 절제된 포인트 | `gold` | `#B8972A` | 얇은 경로선·노드·작은 장식 |
| 기본 따뜻한 배경 | `cream` | `#F5F0E8` | 일러스트 여백·밝은 섹션 |
| 보조 배경 | `creamDeep` | `#F8F3E8` | 세밀한 색면 차이 |
| 역상·대비 | `white` | `#FFFFFF` | 네이비 위 본문·공백 |

- 금색은 밝은 크림 위 주요 본문색으로 사용하지 않는다. 가는 선·작은 강조만 사용한다.
- 새 브랜드 HEX를 생성하지 않는다. 이미지 내 음영·질감은 본문 정보나 필수 대비를 담당하지 않는 부수적 표현으로 제한한다.
- 첫 시안의 회청색·브론즈 색감은 **참고 분위기**다. 최종 리터칭은 위 정본의 네이비·골드에 맞춰 한다.
- 기존 카드뉴스의 '그라데이션 요청 금지'는 그대로 유지한다. 웹 이미지의 자연스러운 질감 표현을 카드 제작 규칙 변경의 근거로 삼지 않는다.

## 4. 그림 언어: 3단계 시각 자산

### Tier A — Signature Artwork (대표 일러스트)

- **이름:** ETHOS Pathways / Structured Entry
- **모티프:** 갈라지는 길 → 다리로 연결 → 순서가 드러나는 계단 → 하나의 아치형 문.
- **사용:** 홈페이지 '업종명이 아니라 사업 구조부터 봅니다' 섹션 한 곳에 우선 사용.
- **모양:** 건축적 구조를 차분한 에디토리얼 아트로 표현. 문자·사람·로고 없음.
- **구도:** PC에서는 4:3 원본을 비율 유지하면서 이미지 영역 38~44% 수준으로; 모바일에서는 제목·핵심 설명 뒤에 그림이 오도록 세로 배치. 그림의 중요한 출구·경로가 잘리지 않게 `contain` 우선.
- **빈도:** 메인 랜딩에서는 원칙적으로 대표 이미지 1장부터 시작. 반복 삽입하지 않는다.

### Tier B — Concept Diagrams (설명형 도식)

새 그림을 늘리기 전에 기존 자체 SVG 6종에서 적합한 것을 재사용한다.

- `assets/illustrations/route.svg`: 상황에 따라 갈라지는 인허가·비자 경로.
- `assets/illustrations/layers.svg`: 법령·업무·제출 순서 등 검토 층위.
- `assets/illustrations/bridge.svg`: 국내·해외 업무 또는 절차 간 연결.
- 나머지 `balance`, `calendar`, `documents`는 실제 문맥에 필요할 때만.

기존 SVG는 `m,s,f,lm,lf,ln,d` 클래스와 브랜드 토큰 매핑을 유지한다. 새 홈페이지용 SVG는 별도 네임스페이스/클래스로 구성하되 토큰 매핑 원칙을 따른다. 승인 카드 SVG를 덮어쓰지 않는다.

### Tier C — Utility Icons (기능형 아이콘)

Lucide/Tabler를 원본 라이선스 기준에 따라 사용. 행정절차의 기한·서류·확인·장소·체류처럼 실제 의미가 있을 때만. 카드뉴스의 기존 `assets.md` 출처 기록과 충돌하지 않도록 채널별 사용 기록을 구분한다.

## 5. 타이포그래피와 화면 구성

- 브랜드에서 사용하는 글꼴 계열: ETHOS Serif(주요 제목), ETHOS Sans·Pretendard(본문), ETHOS Display(핵심 수치). 실제 웹사이트 글꼴은 웹사이트 코드와 라이선스를 확인한 뒤 매핑한다. **카드뉴스 540×675px 타이포 수치를 웹페이지에 그대로 적용하지 않는다.**
- 한 섹션은 **제목 하나 + 구체적 설명 + 단일 시각적 중심**을 우선한다.
- PC 예시: 설명 56~62% / 그림 38~44%. 좌우 공간과 섹션 폭을 기존 홈페이지의 그리드에 맞춘다.
- 모바일 예시: 텍스트 상단, 이미지 하단. 모바일은 복잡한 디테일보다 주요 아치·길의 흐름을 보이게 한다.
- 크림 바탕 + 네이비 구조 + 소량의 골드 선. 텍스트와 이미지를 한데 몰아넣지 않고 충분한 여백을 확보한다.
- 애니메이션은 필수가 아니다. 기본은 정적 이미지. 움직임 도입 시 `prefers-reduced-motion`을 준수하고 반복 동작은 피한다.

## 6. 자산 제작 규격 (제안)

| 자산 | 마스터 | 배포 방식 | 사용 |
|---|---|---|---|
| Signature Artwork | 4:3 고해상도 원본 이미지 | 검토 후 최적화한 AVIF/WebP, 대체 PNG | 홈페이지 설명 섹션 |
| Concept Diagram | 편집 가능한 SVG | 최적화 SVG | 절차·구조 설명 |
| Utility Icon | Lucide/Tabler SVG | 라이선스 유지한 로컬 SVG | UI 보조 |
| SNS 리유즈 | 원본을 바탕으로 별도 크롭·재조합 | 카드뉴스 명세를 지키는 변형본 | 필요할 때만 |

- 이미지 안에 법률 인용·숫자·글자·로고를 생성하지 않는다. 실제 텍스트는 접근 가능한 HTML로 표현한다.
- 장식 이미지라면 `alt=""`, 의미가 있는 도식은 핵심 관계를 설명하는 대체텍스트 제공.
- `width`·`height`를 지정해 레이아웃 이동을 줄이고, `srcset`/`sizes`로 모바일 용량을 줄인다. SVG는 필요한 경우에만 사용한다.
- 다른 세트/채널에서 생성 이미지를 재사용할 때는 AI 생성물임을 내부 자산 기록에 남기고, 실제 증거·사무실·고객 사례로 오인될 표현은 제거한다.

## 7. 제작·검수 흐름

1. **콘셉트 고정:** 업종/사업 구조/절차를 어떤 관계로 보여 줄지 한 문장으로 결정.
2. **시안:** ChatGPT에서 이미지 1~3안 생성. 정본 색상·모티프·금지 표현 준수.
3. **컬러 검토:** 이미지 네이비·골드가 `brand/tokens.json`과 시각적으로 일치하는지 비교. 생성 이미지는 픽셀 단위 정확도를 보장하지 않으므로 필요시 리터칭.
4. **웹 구현:** Codex 또는 웹사이트 작업 환경에서 이미지 최적화, 반응형 배치, 접근성·로딩 점검.
5. **검토:** PC/모바일에서 제목 가독성, 과도한 장식 여부, 이미지 잘림, 시선 흐름, 대비, 오인 가능성 확인.
6. **사람 승인:** 웹사이트 배포 전 결과물을 확인한다. 카드뉴스 기존 자동 렌더·QA와 별개다.

## 8. 첫 적용 제안

**대상 섹션:** "업종명이 아니라 사업 구조부터 봅니다"

- 왼쪽: 이미 있는 제목과 4단계 설명 유지.
- 오른쪽: 앞서 생성한 추상 아치·다리 이미지 1장. 과하게 크거나 전체 섹션 배경이 되지 않게 제한.
- 모바일: 텍스트 → 이미지 순서.
- 핵심 업무 카드·후기·대표 프로필 영역은 당장 재디자인하지 않는다.

**다음 단계:** 웹사이트 저장소의 현재 컴포넌트·스타일과 실제 렌더를 확인해 이 제안을 반영한 별도 PR을 만든다. 이 문서를 머지해도 사이트가 바로 바뀌지는 않는다.

## 9. 향후 제작을 위한 공통 이미지 브리프

> ETHOS Administrative Attorney Office용 프리미엄 미니멀 에디토리얼 일러스트. 추상적 건축 구조, 여러 경로가 명확한 순서로 연결되는 아치·다리·계단. 브랜드 톤: navy #1B2B6B, navyDeep #152056, cream #F5F0E8, 금색 #B8972A은 소량의 얇은 경로선에만. 캐릭터·로고·텍스트·법률 상징물 남용·실제 사무실처럼 보이는 사진풍 장면 금지. 깨끗한 여백, 균형 있는 형태, 차분한 질감, 웹 설명 섹션에 적합한 4:3 구도. 법적 결론이나 실적을 암시하지 않는다.
