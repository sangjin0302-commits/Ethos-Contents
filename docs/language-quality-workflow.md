# 한국어 자연스러움·마케팅 품질 워크플로

이 문서는 `humanize-korean`과 마케팅 스킬을 콘텐츠에 적용하는 순서를 정한다. 스킬은 사실을 만들거나 에토스 지침을 덮어쓰는 권한이 없다.

## 최소 선택 원칙

작업 목적에 맞는 것만 사용한다.

- 주제 기둥·Revenue Cluster·발행 순서: `content-strategy`
- SNS·캐러셀·숏폼의 채널 현지화: `social`
- 새 제목·도입·가치제안·CTA 초안: `copywriting`
- 기존 원고의 명료성·설득 흐름 점검: `copy-editing`
- 사실 검토가 끝난 한국어의 최종 문체 교정: `humanize-korean`

모든 스킬을 한 원고에 적용하지 않는다. 일반적인 바이럴 공식, 고정 발행 빈도, 자극적인 Hook이 에토스 지침과 충돌하면 사용하지 않는다.

## 실행 순서

1. 원문과 공식 근거를 확인한다.
2. Evidence Label과 Source Trace를 잠근다.
3. 채널과 목표에 맞춰 초안을 작성한다.
4. 마케팅 검토에서 대상 독자, 실용적 보상, Proof of Work, Reader Boundary, CTA를 확인한다.
5. 게시용 한국어에만 `humanize-korean`을 보수적으로 적용한다.
6. 윤문 전후를 비교해 사실·숫자·날짜·고유명사·법률용어·인용·CTA 범위가 같은지 확인한다.
7. 문제가 있으면 윤문한 문장을 롤백하고 원문을 사용한다.

## humanize-korean 보호 범위

다음은 바꾸지 않는다.

- 법령명·조문·판례·재결례·기관명
- 숫자·날짜·금액·기한·비율
- 직접 인용·출처·고유명사
- 공식 용어와 Evidence Label
- 사실관계와 법률상 조건·예외
- 무료 검토, 유료 상담, 수임의 범위

윤문은 번역투, 기계적 병렬, 관용구, 접속사 반복, 문장 리듬을 다듬는 데 한정한다. 새로운 경험담·비유·성과·긴급성·감정을 추가하지 않는다. 변경률이 30%를 넘거나 보호 범위가 달라지면 결과를 사용하지 않는다.

## 카드뉴스 적용 시점

- 카드 카피: card-data 승인 **전**에만 윤문할 수 있다. 승인 뒤에는 Source Lock을 우선하며 다시 윤문하지 않는다.
- 캡션·alt text: 사실 검토 후 발행 직전에 윤문할 수 있다.
- 영문·아랍어: `humanize-korean` 대상이 아니다. 각 언어의 별도 현지화·검수 절차를 사용한다.

## 실패하지 않는 운영

스킬을 사용할 수 없으면 사용한 것처럼 말하지 않는다. 수동 체크리스트로 번역투·반복·과장·기계적 병렬을 점검하되, 스킬 부재 때문에 콘텐츠 생성을 중단하지 않는다. 자연스러움 점수는 권고이며 사실·법률·원본 정합성을 통과한 콘텐츠를 불필요하게 막지 않는다.
