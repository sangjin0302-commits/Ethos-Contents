# 사진·삽화·외부 자산 정책

사진과 삽화는 카드의 상황이나 판단을 더 빨리 이해시키는 경우에만 사용한다. 시각적 빈칸을 채우려고 넣지 않는다.

## 허용 기준

- 국가·산업·장소·업무 흐름을 실제로 설명하는 사진
- 개인정보가 제거된 공개 문서 조각이나 승인된 모형 문서
- 판단 순서와 관계를 보여주는 도식
- 사용권과 출처를 확인한 아이콘·사진·삽화
- 실제 자료가 아님을 명확히 구분한 보조 이미지

## 금지·주의

- 비상주 사무실을 상주 사무실이나 대형 조직처럼 보이게 연출하지 않는다.
- 스톡 악수·회의·상담 사진을 실제 고객이나 업무 현장처럼 제시하지 않는다.
- 생성 이미지를 실제 사건·고객·사무실·공식 문서처럼 보이게 사용하지 않는다.
- 이미지 생성 모델에 한글·영문·아랍어 본문, 로고, 법률 인용을 그리게 하지 않는다.
- 개인정보·서명·등록번호·사건 식별정보를 노출하지 않는다.
- 출처나 이용조건을 확인할 수 없는 자산은 사용하지 않는다.

## 기록

외부 자산을 사용하면 원본 URL 또는 파일 출처, 제작자, 라이선스, 확인일, 수정 여부를 작업 폴더에 기록한다. 생성 이미지라면 생성 이미지임을 기록하고 실제 자료와 혼동되지 않게 한다.

기록 위치는 content/<ID>/assets.md다. 외부 자산을 사용하지 않으면 EXTERNAL ASSETS: No를 유지한다. 사용했다면 Yes로 바꾸고 자산마다 원본 URL·제작자·라이선스·확인일·수정 여부를 채운 뒤 scripts/validate_distribution.py를 실행한다.

사진이 없어도 큰 제목, 공개 근거, 비교, 절차, 여백만으로 충분하면 텍스트 중심 디자인을 우선한다.
