# 사진·삽화·외부 자산 정책

사진과 삽화는 카드의 상황이나 판단을 더 빨리 이해시키는 경우에만 사용한다. 시각적 빈칸을 채우려고 넣지 않는다.

## 허용 기준

- 국가·산업·장소·업무 흐름을 실제로 설명하는 사진
- 개인정보가 제거된 공개 문서 조각이나 승인된 모형 문서
- 판단 순서와 관계를 보여주는 도식
- 사용권과 출처를 확인한 아이콘·사진·삽화
- 실제 자료가 아님을 명확히 구분한 보조 이미지

## 벡터 아이콘

`assets/icons/lucide/`에 Lucide(ISC) 아이콘을, Lucide에 없는 이름은 `assets/icons/tabler/`에 Tabler(MIT) 아이콘을 원본 그대로 보관한다(빌더는 Lucide를 먼저 찾는다). 카드는 card-data의 `icon`(제목 줄 원형 배지), `art`(표지 상황 삽화), 항목별 `icon`으로 이름만 지정하고, 빌더가 인라인 SVG로 넣는다. 외부 네트워크 호출은 없다.

- 아이콘은 판단 구조를 시각 앵커로 보강할 때만 쓴다. 한 세트에서 의미 없이 모든 카드에 같은 위치로 붙이지 않는다.
- 새 아이콘은 같은 폴더에 원본 그대로 추가하고, 사용 세트의 `assets.md`에 `lucide/<이름>.svg` 또는 `tabler/<이름>.svg` 한 줄을 적는다(`copy_lint.py`가 누락을 경고한다).
- 아이콘은 정보를 대체하지 않는다. 알려 줄 내용은 반드시 글로도 있어야 한다.

## 자체 제작 일러스트

`assets/illustrations/`의 평면 일러스트 6종은 이 저장소에서 직접 그린 도형이다. 외부 자산이 아니므로 `assets.md`에 기록하지 않아도 된다(아이콘만 쓰면 기존처럼 Lucide를 기록한다). 새 일러스트를 추가할 때는 `m`(주색)·`s`(보조색)·`f`(앞면)·`lm`·`lf`·`ln`·`d` 클래스만 쓰고 색을 직접 지정하지 않는다. 그래야 navy·cream 어디서나 대비를 통과한다.

## 인물 장면 일러스트 (Open Peeps, CC0)

`assets/illustrations/people/`의 인물 5종(서류를 든 걱정, 설명, 온라인 신청, 차분한 사장님, 안내)은 Open Peeps(CC0)를 브랜드 색으로 바꾼 것이다. **크림(베이지) 카드에서만 쓴다.** 네이비 배경 위 인물은 어색하다는 사용자 피드백(2026-10-06)에 따른 것이다. 네이비 카드에는 아래 물건 그림을 쓴다.

- 생활 장면형 표지처럼 "누가 어떤 상황인지"를 2초 안에 보여 줄 때만 쓴다. 본문 카드의 장식으로 쓰지 않는다.
- 특정 고객·사건·직원처럼 보이게 쓰지 않는다. 표정은 상황(걱정·설명)까지만, 과장된 공포·분노 표정은 쓰지 않는다.
- 쓰면 `assets.md`에 `open-peeps/<파일 이름>`과 CC0을 한 줄 적는다.

## 물건 일러스트 (Phosphor duotone, MIT)

`assets/illustrations/objects/`의 물건 30종(도장·저울·서류·신분증·가게·달력·모래시계·비행기 등)은 네이비·크림 어느 카드에나 쓴다. 선은 배경 반대색, 면은 골드다. 쓰면 `assets.md`에 `phosphor/<이름>`과 MIT를 적는다(`copy_lint.py`가 `data-asset` 값으로 누락을 경고).

## 손그림 선화 (IRA Design Outline, MIT)

`assets/illustrations/hand/`의 물건 13종·인물 6종은 IRA Design의 선화(Outline) 버전을 브랜드 토큰 색으로 바꾼 것이다. 그라데이션 버전은 쓰지 않는다. 인물은 크림 카드에서만 쓴다. 쓰면 `assets.md`에 `ira/<이름>`과 MIT를 적는다.

## 금지·주의

- 비상주 사무실을 상주 사무실이나 대형 조직처럼 보이게 연출하지 않는다.
- 스톡 악수·회의·상담 사진을 실제 고객이나 업무 현장처럼 제시하지 않는다.
- 생성 이미지를 실제 사건·고객·사무실·공식 문서처럼 보이게 사용하지 않는다.
- 이미지 생성 모델에 한글·영문·아랍어 본문, 로고, 법률 인용을 그리게 하지 않는다.
- 개인정보·서명·등록번호·사건 식별정보를 노출하지 않는다.
- 출처나 이용조건을 확인할 수 없는 자산은 사용하지 않는다.

## 기록

외부 자산을 사용하면 원본 URL 또는 파일 출처, 제작자, 라이선스, 확인일, 수정 여부를 작업 폴더에 기록한다. 생성 이미지라면 생성 이미지임을 기록하고 실제 자료와 혼동되지 않게 한다.

기록 위치는 content/<ID>/assets.md다. 외부 자산을 사용하지 않으면 EXTERNAL ASSETS: No를 유지한다. 사용했다면 Yes로 바꾸고 자산마다 원본 URL·제작자·라이선스·확인일·수정 여부를 채운 뒤 scripts/validate_distribution.py를 실행한다.

사진이 없어도 큰 제목, 공개 근거, 비교, 절차, 여백만으로 충분하면 텍스트 중심 디자인을 우선한다.
