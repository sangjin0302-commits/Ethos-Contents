# 사실·법률 검증 체크리스트

게시용 글·SNS·카드의 사실 검증 단계(`docs/language-quality-workflow.md` 2~3단계)에서 쓰는 한 장 점검표다. 법령 해석의 정확성은 이 표가 보증하지 않는다. 사람이 최종 확인한다.

## 1. 기준일과 출처

- 모든 글·카드 세트에 **확인 기준일**(`FRESHNESS VERIFIED ON`)을 적는다. 기준일 없는 법률·제도 문장은 발행하지 않는다.
- 법령은 국가법령정보센터(law.go.kr)의 현행 본문을 기준으로 한다. 시행 예정 개정이 있으면 현행 조문과 시행 예정 조문을 구분해 쓴다.
- 법령 조회 도구(`korean_law` MCP 등)를 쓸 수 있으면 조문 원문을 직접 조회해 문장과 대조한다. 쓸 수 없으면 쓴 것처럼 말하지 않고, 공식 사이트에서 사람이 확인할 조문 목록을 완성본 뒤에 붙인다.
- 판례는 법원명·사건번호·선고일, 재결례는 기관명·의결번호·의결일을 확인한다. 확인하지 못한 판례·재결례는 쓰지 않는다.
- 블로그 원문이 이미 승인돼 있으면 카드·SNS는 그 원문을 Source Lock으로 삼고 새로 조사하지 않는다.

## 2. 증거 라벨

내부 점검용으로 문장마다 F(확인된 사실), I(추론), S(설명용 가상), U(미확인)를 구분한다. U는 발행하지 않는다. 라벨 정의는 `guidelines/core/top-level.md` §4.

## 3. 에토스 콘텐츠에 걸리는 행정사법 조항 (2026-10-06 조회)

발행 전 현행 본문을 다시 확인한다. 아래는 조항 위치를 찾기 위한 목록이며 해석이 아니다.

| 조항 | 콘텐츠에서 점검할 것 |
|---|---|
| 행정사법 제22조 제5호 | 업무에 관한 거짓 표시, 객관적 사실의 과장·누락으로 소비자를 오도할 우려가 있는 광고 금지. 성공률·처리 건수·"최고"류 표현, 확인되지 않은 수치를 쓰지 않는다 |
| 행정사법 제22조 제4호 | 공무원과의 연고 등 사적 관계를 내세워 영향력을 미칠 수 있다고 선전하는 행위 금지. 기관 담당자와의 친분·"심사자 시각" 같은 표현을 영향력 암시로 쓰지 않는다 |
| 행정사법 제22조 제3호 | 행정사 업무 범위를 벗어난 소송·권리관계 분쟁·민원 개입 금지. 법정 업무범위를 넘는 대리를 약속하지 않는다 |
| 행정사법 제23조 | 직무상 알게 된 사실의 누설 금지. 실제 상담·의뢰 내용은 익명화해도 개별 사안으로 특정될 수 있으면 쓰지 않는다 |
| 행정사법 제15조 | 사무소 명칭 표기(행정사사무소 등). 사무소 형태를 사실과 다르게 연출하지 않는다 |
| 행정사법 제21조 | 품위 유지·성실 의무. 공포·긴박감 조작이나 다른 자격사 비하는 쓰지 않는다 |

변호사·법무사·세무사·노무사 등 다른 자격사의 업무 영역에 대한 문장은 해당 자격사법 조문으로 따로 확인한다.

## 4. 글에서 반복되는 위험 표현

- "처리했다", "다뤄 본" 같은 경험 서술은 실제로 있었던 일만 쓴다(`MANIFEST.md` 공통 고정 원칙).
- "무료 상담" 표현 금지. 무료 검토의 범위는 웹사이트 저장소 운영정책(`docs/brand-philosophy.md` §6)을 넘기지 않는다.
- "A는 B만 하면 된다"처럼 조건·예외를 지우는 단정을 쓰지 않는다. 원문의 "또는/그리고/~할 수 있다"를 그대로 둔다.

## 5. 기록

사람이 확인할 항목(`humanChecks`)에 다음을 남긴다: 확인 기준일, 직접 대조한 조문 목록, 대조하지 못한 항목과 이유.
