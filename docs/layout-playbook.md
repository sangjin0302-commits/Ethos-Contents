# ETHOS BRIEF Layout Playbook

규칙을 맞추기 위한 레이아웃 목록이 아니라, 메시지에 가장 자연스러운 구도를 고르기 위한 플레이북이다. 기준 이미지는 `references/golden/game-overseas-en/`이다.

## 선택 순서

1. 이 카드에서 기억할 문장을 하나만 정한다.
2. 그 문장이 질문·근거·비교·구분·기준·행동 중 무엇인지 고른다.
3. 아래 구도 중 하나를 선택하고, 정보가 넘치면 글자를 줄이지 말고 다음 카드로 나눈다.
4. 같은 구도를 반복할 수는 있지만 세트 전체가 양식집처럼 보이지 않게 크기·여백·배경 리듬을 바꾼다.

## 검증된 구도

| 메시지 역할 | 권장 구도 | 가까운 레퍼런스 | 핵심 미감 |
|---|---|---|---|
| 표지 질문 | 대형 세리프 질문 + 짧은 결론 패널 | 01 | 설명보다 질문을 크게, 요소 3개 이하 |
| 판례·공식 근거 | 근거 라벨 + 흰 패널 + 한 줄 결론 | 02 | 권위는 이력이 아니라 자료로 표현 |
| 당사자·개념 구분 | 2×2 균형 그리드 + 하단 결론 | 03 | 네 칸의 구조와 문장 길이를 맞춤 |
| 두 상황의 차이 | A/B 카드 + 중앙 대비 기호 + 결론 | 04 | 서로 같은 정보 구조, 결론은 한 번만 |
| 두 규정·두 기준 | 가로 구획 2개 + 하단 핵심 문장 | 05 | 박스보다 타이포그래피와 선으로 구분 |
| 판단 질문 | 설명 패널 + 3개 질문 셀 + 결론 | 06 | 질문은 짧게, 셀은 같은 무게로 |
| 역할과 한계 | 좌우 2열 + 하단 경고·결론 | 07 | 무엇을 하는지와 대체하지 않는 것을 대비 |
| 수치 기준 | 큰 수치 라벨 + 설명 행 + 결과 | 08 | 숫자는 원문 그대로, 장식이 아니라 탐색점 |
| 자가 확인 vs 검토 | 좌우 2열 체크 + 종합 결론 | 09 | 독자가 자기 위치를 바로 찾게 함 |
| 마지막 행동 | 2열 체크리스트 + 절제된 CTA | 10 | 판매 문구보다 판단 항목, CTA는 한 번 |

## 세트 리듬

- 기본 배경은 Navy → Cream → Navy → Cream의 리듬을 출발점으로 삼되 메시지 역할에 따라 바꿀 수 있다.
- 한 카드의 지배적 시각 요소는 하나다: 큰 질문, 큰 숫자, 비교, 리스트, 결론 중 하나만 주연으로 둔다.
- Gold는 시선을 여는 번호·키워드·선에 제한한다. 긴 본문 전체를 Gold로 칠하지 않는다.
- 카드 사이에 밀도 차이를 만든다. 모든 장을 같은 양의 텍스트와 같은 박스로 채우지 않는다.
- 270px 축소 시트에서 첫 시선의 위치와 배경 리듬이 자연스럽게 이어지는지 본다.

## 자유롭게 바꿔도 되는 것

- 카드 수, 권고 글자 수, 제목 줄 수, 영역 수, 여백 크기
- 메시지에 맞춘 행·열 비율과 패널 위치
- 같은 디자인 계보 안에서의 세리프 크기와 줄바꿈

## 바꾸면 안 되는 것

- 사실·숫자·한정어의 의미
- 로컬 폰트, 브랜드 팔레트, 공통 프레임
- 오버플로·클리핑 없는 1080×1080 출력
- 카드당 하나의 핵심 판단과 국·영문 간 사실 구조
