# 윤리적 설득 원칙

에토스의 마케팅은 독자의 판단을 돕고 다음 행동의 부담을 낮춘다. 불안·편향·정보 격차를 이용해 결정을 밀어붙이지 않는다.

## 사용할 원칙

### 유용한 답을 먼저 제공한다

상호성은 무료 자료를 미끼로 쓰는 방식이 아니다. 독자가 검색한 질문에 실제로 도움이 되는 답과 확인 기준을 먼저 제공한다. CTA를 지워도 콘텐츠가 유익해야 한다.

### 권위는 판단 과정으로 보여준다

자격과 경력을 반복하기보다 공식자료를 읽는 방식, 문서의 불일치를 찾는 과정, 기관에 확인할 질문을 보여준다. 실제 증거가 없는 사회적 증거는 만들지 않는다.

### 작은 자기점검을 돕는다

독자가 자신의 자료·단계·조건을 확인할 수 있게 한다. 자기점검은 의뢰를 압박하는 장치가 아니라 직접 처리 가능한 사안을 구분하는 장치다.

### 선택지를 줄인다

한 게시물에는 Primary Action을 하나만 둔다. 저장·공유·프로필 방문·무료 검토를 모두 같은 무게로 요구하지 않는다. 글의 구매 단계에 맞는 행동 하나를 선택한다.

### 시작 부담을 낮춘다

무료 검토가 필요한 글에서는 받을 자료와 확인 결과를 구체화한다. 상세 전략·완성 서류·결과 예측이 무료라고 암시하지 않는다.

### 익숙함은 일관성으로 만든다

신사업 인허가·국제화·외국인 관련 행정이라는 브랜드 축, 네이비·크림·골드, 정확한 판단 문체를 반복한다. 같은 문장과 같은 레이아웃을 반복하는 것은 일관성이 아니다.

## 사용하지 않을 원칙

- 실제 제한이 없는 허위 희소성·마감
- 불허·손해·처벌을 부풀리는 손실회피
- 없는 후기·처리 건수·고객 수를 이용한 사회적 증거
- 높은 가격이나 성공률로 인상을 조작하는 앵커링
- 질문만 던지고 답을 숨기는 가짜 미완결 효과
- 선택을 어렵게 만드는 여러 CTA와 연락처 디렉터리

## 적용 질문

1. 독자가 이 콘텐츠를 보는 이유는 무엇인가?
2. 읽은 뒤 무엇을 판단하거나 준비할 수 있는가?
3. 다음 행동을 막는 불확실성은 무엇인가?
4. 그 불확실성을 정확한 정보·Proof of Work·구체적 CTA 중 무엇으로 줄일 것인가?
5. 실제 데이터 없이 심리 효과를 성과로 단정하고 있지 않은가?

설득 원칙은 가설이다. 실제 저장·프로필 방문·적합 문의·수임 데이터로 검증하고, 사실·법률·독자의 자기결정권보다 우선하지 않는다.
