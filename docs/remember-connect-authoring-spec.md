# 리멤버 커넥트 실명 개인 게시글 작성·배포 명세 v1.1

> 적용: 리멤버 커넥트(Connect) SNS의 개인 프로필 게시글. 리멤버 커리어 채용공고 및 기존 리멤버 커뮤니티와 구분한다.
> 정책 확인: 2026-10-26 / 리멤버 커넥트 이용 가이드라인 2026-09-24 시행본
> 정본 연결: MANIFEST.md → docs/sns-authoring-spec.md → guidelines/channels/sns.md → 이 채널 특칙. 충돌 시 사용자 직접 지시와 상위 Hard Gate를 지키되, 커넥트 운영정책을 위반하는 게시물은 발행용으로 만들지 않는다.

## 1. 역할과 독자

이 채널은 에토스 행정사사무소 명의의 기업 광고판이 아니라 **실제 행정사가 자신의 이름으로 직업적 판단을 공유하는 비즈니스 SNS**다. 기업 대표, 인사·총무·운영·인허가 담당자가 업무에서 부딪히는 하나의 문제에 설명 가능한 답을 주고, 자연스럽게 전문성과 신뢰를 보여준다.

- 주된 콘텐츠 목표는 **이해·저장·신뢰·건설적인 업계 대화** 중 하나다. 판매 문의와 무료 검토 획득을 일반 게시물의 직접 목표로 놓지 않는다.
- 블로그는 충분한 칼럼, 카카오는 구독자에게 빠른 판단 정보, LinkedIn은 기업 의사결정, **커넥트는 실명 전문인의 현업 관찰·문서 판단·공적인 질문과 답**에 무게를 둔다.
- 적합한 소재의 예: E-7 고용 시 계약서와 실제 직무를 대조해야 하는 질문, 화장품 책임판매업자가 OEM 제조사와 확인할 문서, 업종별 인허가의 신청 주체·기관 구분, 처분 통지서에서 먼저 읽을 사항. 이 예시는 글감이지 새로운 법률 결론이 아니다.
- 정치적 찬반이나 일과 무관한 사담은 게시하지 않는다. 관련 제도 변화는 업무상 적용 요건에 집중해 비정치적으로 설명한다.

## 2. 플랫폼 정책 Hard Gate (일반 게시물)

1. **개인 실명 계정**: 실제 성명·직무·대표 회사명 등 필수 프로필을 사실에 맞게 둔다. 소속 사무소는 실제 경력으로 표기할 수 있지만 사무소 이름·로고를 앞세운 기업용 계정으로 바꾸지 않는다. 기업 계정은 리멤버가 정한 별도 승인 절차를 확인하기 전 운영하지 않는다.
2. **정보 공유와 영업의 구별**: 무분별한 광고, 유료 자문 섭외, 가입·결제만을 유도하는 게시물은 금지/제한 대상이 될 수 있다. 일반 게시물에서는 서비스 가격, 혜택, 수임 권유, 무료 검토 신청, 상담 예약, DM 요청 등 직접 영업 CTA를 기본적으로 넣지 않는다.
3. **우회 홍보도 금지**: 본문 대신 첫 댓글·이미지·해시태그·프로필 이동 요구·무단 DM으로 신청 링크나 상담 유도를 숨기지 않는다. 기존 카카오·블로그의 CTA와 접수 링크를 자동 복사하지 않는다.
4. **링크 구분**: 검증된 법령·기관의 원자료를 이해를 돕기 위해 제시하는 것은 별도로 판단한다. 사무소 홈페이지·블로그·접수·상품 링크는 일반 게시물에서 홍보 유도 목적으로 넣지 않는다. 공식 링크도 클릭 수집용으로 반복하지 않는다. 모든 외부 링크가 플랫폼상 전면 금지라고 단정하지 않는다.
5. **금지 행위**: 본인 이력·성과·실제 상담 창작, 타인 사칭, 기망형 AI 이미지, 개인정보·비밀정보 공개, 타 게시물 무단 수집·전재, 반복 도배·삭제 후 재게시, 자동 반응 조작, 무관한 채용·헤드헌팅 접근을 하지 않는다. 수신자의 동의 없는 메시지 영업을 운영방식으로 삼지 않는다.
6. **별도 홍보 프로젝트**: 리멤버가 허용한 공식 광고상품 또는 별도 승인이 실제로 확인될 때만 승인된 범위·표시·링크·문구에 따라 **별도 원고**를 만든다. 일반 게시물에 대한 상업적 홍보 허용을 추정하지 않는다.

정책 적용 범위는 커넥트다. 기존 '리멤버 커뮤니티 가이드라인'을 커넥트 정책 대신 사용하지 않는다. 운영정책이 바뀌거나 계정·광고 승인 여부가 불명확하면 게시 전에 다시 확인한다.

## 2-1. 개인 프로필과 자연 유입 연결 (간접 홍보)

- **실명 행정사 개인을 중심으로 프로필을 정비한다.** 직무, 실제 사무소 소속·대표 경력, 보유 자격과 실제 담당 분야를 사실대로 기재한다. 조직 규모, 상주 사무실, 수임 건수, 제휴·성과를 부풀리지 않는다. 브랜드명이나 로고로 개인 프로필을 기업 광고 계정처럼 꾸미지 않는다.
- 리멤버가 제공하는 **커넥트용 소개와 경력 상세 설명**을 채용 서비스용 소개와 구분해 설정할 수 있다. 전문분야·자격증·웹사이트·블로그 항목은 실제 제공되는 공개 범위 설정 안에서 정보성으로 구성할 수 있다. 홈페이지 주소를 프로필의 정식 필드에 사실대로 기재하는 것과 피드 글마다 접수·상담 URL을 반복 삽입하는 것은 다르다.
- 처음 보는 실무자도 담당 분야와 판단 방식을 이해하도록 소개한다. 예: '외국인 채용과 기업 인허가 과정에서 신청 요건과 계약서·증빙자료의 정합성을 검토하는 행정사' — 실제 수행 중인 업무와 자격이 확인된 경우에만 쓴다.
- 게시글에는 독자가 직접 활용할 수 있는 실무 기준을 충분히 제공하고, **'프로필로 오세요', 'DM 주세요', '블로그에서 이어 읽으세요'** 같은 유도 문장을 습관적으로 붙이지 않는다. 관심 있는 독자가 정상적인 프로필 기능으로 경력·공개 자료를 알아보는 **자발적인 흐름**을 목표로 한다.
- 리멤버 앱의 '내 정보'에서 커넥트용 소개·경력 설명과 웹사이트·블로그 항목의 공개 범위를 별도로 설정할 수 있다. 발행 전 실제 공개 미리보기를 확인한다. 인터페이스가 바뀌면 공식 최신 안내를 다시 확인한다.
- 성과 측정에서는 커넥트 피드의 실무 대화, 자발적 관계 형성, **확인 가능한** 프로필 방문·홈페이지 유입·적합 문의를 각각 구분한다. 플랫폼이 제공하지 않는 추적 데이터나 인과관계를 만들어내지 않는다.

## 3. 글의 기획과 문체

- 하나의 독자 문제와 직접 답 하나를 선택한다. 제목이나 첫 1~2문단에서 실무 상황과 핵심 판단이 함께 드러나야 한다. 고정 시리즈명·회차 머리표는 제목과 첫 줄에 노출하지 않고 내부 콘텐츠 ID로 연결한다.
- 권장 전개(고정 목차 아님): **실무에서 생기는 질문 → 짧고 명확한 답 → 판단이 달라지는 요건·원문 근거 → 서로 맞춰 볼 문서·기관·순서 → 독자가 직접 확인할 것**.
- 문서 두 개의 내용이 다르거나 담당부서가 서로 다르게 이해하는 지점을 짚어 쉽게 풀어 쓴다. 행정사가 다룰 수 있는 작성·확인 업무와 행정기관의 최종 결정, 변호사 등 다른 전문자격사의 독점업무를 분명히 구분한다.
- 독자가 바로 쓸 수 있는 확인 항목을 남기되 상담 신청을 해결책으로 끝맺지 않는다. 예시 대화는 원문에 있거나 신규 Source Brief로 검증된 경우에만 사용하고 실제 고객의 경험처럼 쓰지 않는다.
- 핵심 법률 결론을 감추는 낚시성 첫 문장, 공포 조장, AI가 쓴 듯한 반복 수식, 자기소개·경력·자격 나열로 시작하기, 매 글 같은 문장으로 결론 내리기를 피한다.
- **장문 블로그 축약본 또는 카카오톡 글의 복사본으로 만들지 않는다.** 원문은 사실과 조건의 잠금자료로 사용하고, 커넥트에서는 기업 담당자의 결정 하나에 맞춰 다시 쓴다.

## 3-1. 게시 주제(카테고리) 선택 원칙 — 실무 질문과 업종 우선

> 입력 근거: 사용자가 2026-10-26 제공한 리멤버 커넥트 게시 화면에 보이는 주제 선택지 15개. 이는 **화면에서 확인한 명칭과 에토스 내부 편집 분류**이며 리멤버가 공식 권장한 주제 순위, 카테고리별 도달률, 노출 알고리즘 또는 복수 선택 가능 여부를 뜻하지 않는다. 실제 선택지/선택 방식이 바뀌면 에디터 화면을 기준으로 갱신한다.

**기본 결정**: 에토스 전체 게시물에 하나의 카테고리를 고정하지 않는다. 한 게시물의 **주된 업종과 독자가 해결하려는 실무 문제**를 보고 가장 맞는 주제 **하나를 우선 추천**한다. 글 본문의 중심 판단과 관련 없는 분야에 억지로 끼워 넣지 않는다. '행정사'나 '법률'이라는 별도 주제는 현재 제공된 화면에 없으므로 임의로 만들지 않는다.

| 리멤버 주제(화면 표기) | 우선 선택하는 경우 — 원고 핵심 질문 기준 |
|---|---|
| **경영 전략** | 업종을 가로지르는 기업 계약·리스크·인허가 후 운영·영업정지 대응·외국인 **고용기업 측** 계약과 관리 문제 |
| **스타트업·창업** | 창업자가 신규 업종을 시작하기 위한 인허가, 사업 구조·설립, 외국인 창업자의 사업 개시 요건 |
| **커머스·유통** | 온라인 판매·3PL·풀필먼트·재고 불일치·입출고·반품·유통계약·판매정산 |
| **뷰티·패션** | 화장품 브랜드 창업·책임판매업·OEM 제조·원료·표시·제품관리처럼 **뷰티 업종 고유**의 문제 |
| **마케팅·브랜드** | 플랫폼 광고비·광고대행 계약·광고 중단 후 정산·홍보 문구와 광고 표시가 중심인 문제 |
| **부동산·건축·도시** | 토지취득·건축물 용도·개발 인허가·숙박시설 입지와 건물 요건이 핵심인 문제 |
| **미디어·콘텐츠** | 게임업·영상·콘텐츠 플랫폼의 업종별 신고·허가와 콘텐츠 계약 |
| **조직문화·리더십** | 사내 인력운영·인사절차·조직 내 역할과 책임 배분 자체가 핵심인 경우. E-7 비자 글 전부에 붙이지 않는다 |
| **커리어·자기계발** | 기업 채용이 아니라 **근로자·지원자 개인**의 취업·경력·자격 선택이 중심인 경우 |
| **바이오·헬스케어** | 헬스케어·의료기기·바이오 사업의 해당 산업 고유 규제·인허가가 직접 쟁점인 경우 |
| **경제·금융** | 금융서비스·금융 규제·금융거래 구조 자체가 중심인 경우. 일반적인 과징금·계약금·배상금만으로 선택하지 않는다 |
| **AI·테크** | AI·IT 서비스 모델 자체의 규제·인허가·계약이 중심인 경우. 콘텐츠 작성에 AI를 사용했다는 이유로 선택하지 않는다 |
| **반도체·배터리** | 반도체·배터리 산업에 특화된 사업 요건·인허가가 핵심인 경우에만 선택 |
| **문화·예술** | 예술·문화 사업, 관련 기관·단체의 인허가나 계약이 핵심인 경우 |
| **자유 주제** | 일반적인 행정심판·행정사 업무범위 등 업종/독자 직무가 다른 선택지에 자연스럽게 들어가지 않을 때 최후에 선택 |

**겹칠 때 판단 순서**

1. 제목의 핵심 질문과 본문의 **직접 답**이 다루는 업무를 우선한다. 검색량이나 '더 많이 노출될 것'이라는 미확인 가정으로 카테고리를 바꾸지 않는다.
2. 특정 산업 고유 규제가 중심이면 **해당 업종 카테고리**를 우선한다(화장품 OEM 품질·안전성 → 뷰티·패션). 기업 전반의 운영 리스크라면 경영 전략, 새 사업 개시가 중심이면 스타트업·창업으로 분류한다.
3. 한 글에 둘 이상의 업종이 언급돼도 **주된 독자**와 실제 설명의 중심을 본다. 같은 블로그 시리즈라도 회차마다 서로 다른 주제를 선택할 수 있다.
4. 원고의 소재를 바꾸거나 법률상 조건을 삭제해 선택 카테고리에 맞추지 않는다. 적절한 선택지가 없다면 자유 주제를 택하거나, 실제 글 주제를 다시 검토한다.
5. 게시 UI가 복수 선택을 허용하는지 현재 확인되지 않았으므로 **기본 배포 메모에는 1개만 추천**한다. 향후 UI가 복수 선택을 지원하는 것으로 확인돼도 무관한 주제를 덧붙이지 않는다.

**에토스 원고 예시 — 최종 판단은 회차별 본문 기준**

- '창고 재고 1,200개/1,150개/1,130개·3PL 책임' → **커머스·유통**. 장부와 실물 수량, 물류계약이 중심이다.
- '화장품 OEM 계약·책임판매관리자·원료목록' → **뷰티·패션**. 제품·업종 고유 요건이 중심이다.
- 'E-7 인력을 채용할 때 직무·근무조건·서류 일치' → **경영 전략**. 기업의 인사·운영 의사결정이 중심이다.
- '외국인 창업자가 사업을 시작하기 전 검토할 체류·인허가' → **스타트업·창업**. 사업 시작이 중심이다.
- '플랫폼 광고 종료 후 광고비 공제·정산' → **마케팅·브랜드**. 광고거래와 과금조건이 중심이다.
- '숙박업 영업정지와 처분기준' → **경영 전략**. 기존 사업의 운영·행정처분 대응이 중심이다. 건축물 용도·입지 문제를 다룬 회차라면 **부동산·건축·도시**.
- '게임업 신고·등록의 산업별 요건' → **미디어·콘텐츠**. 일반 창업 단계 자체가 핵심인 별도 글이라면 **스타트업·창업**.
- '외국인이 자신의 구직·경력 경로를 선택하는 문제' → **커리어·자기계발**. 반대로 회사의 고용 자격심사가 쟁점이면 **경영 전략**.

**출력·기록**: 리멤버 게시글을 완성할 때에는 게시물 본문 **바깥의 발행 메모**에 `추천 주제: [화면에 보이는 정확한 선택지 1개]`와 선정 이유 1문장을 덧붙인다. 사용자에게 게시글만 달라는 요청이라면 메모는 짧게 따로 제공하거나 생략한다. 배포 기록이 있는 경우 기존 `content_id`와 `channel=remember_connect`를 유지하고 주제 선택을 기존 주제/분류 필드 또는 별도 발행 메모에 남긴다. 승인되지 않은 신규 스키마 키·시트 열·필수 출력 형식을 임의로 추가하지 않는다.

## 4. 발행 형식

- 기본 언어는 **한국어**, 형식은 게시창에 복사 가능한 **서식 없는 일반 텍스트**다. 제목과 문단 사이 실제 빈 줄을 두고 문장을 모두 한 줄씩 쪼개지 않는다. 마크다운 굵게 표시(**), 제목 기호(###), 가짜 줄바꿈을 공개 원고에 남기지 않는다.
- 길이는 정보의 복잡도에 따라 정하며 인위적 고정 글자수·줄수·문단수를 두지 않는다. 간결한 단문과 근거가 필요한 긴 글을 모두 허용하되 반복·중복을 지운다. 플랫폼의 글자수 상한·이미지 크기·태그 인식·링크 미리보기·게시 편집기 동작을 직접 확인하지 못했다면 확정 규정처럼 적지 않는다.
- 해시태그는 의무가 아니다. 실제 플랫폼 노출효과가 검증되지 않은 수량·알고리즘 최적화 법칙을 만들지 않는다. 허용·효과가 확인될 때만 주제와 실제로 맞는 소수의 태그를 검토한다.
- 이미지가 설명에 필요한 경우에만 독자적 도표·문서 대조 그림·승인된 카드뉴스 일부를 재구성한다. 사무소 로고 중심 광고 이미지, 허위 인물·상담 현장 이미지, 개인정보나 저작권 문제가 있는 화면은 쓰지 않는다. 이미지/캐러셀 지원 여부는 실제 에디터에서 확인한다.
- 일반 게시물의 마무리는 **지금 대조할 문서나 적용 판단 질문**으로 한다. '무료로 검토해 드립니다', '문의 주세요', '프로필 링크를 확인하세요' 등을 자동 부착하지 않는다.

## 5. 출처 잠금과 윤문

- 승인된 블로그에서 파생할 때는 해당 content/<ID>/blog.md를 Source Lock으로 삼는다. 승인 원문에 없는 판례·재결례·통계·새 상황·서비스 약속을 추가하지 않는다. 새 내용이 필요하면 원문 또는 신규 Source Brief에서 검증·승인한 후 사용한다.
- 법령·고시·공식 안내·사건 원문·조사자료의 실제 근거를 우선한다. 기사만으로 법률 결론을 단정하지 않는다. 근거의 판본·확인일은 내부 research/검수 기록에, 실제 시행일·처분일처럼 설명에 필요한 날짜는 본문에 남긴다.
- '또는', '이하', '할 수 있다', 기한·숫자·주체·의무와 재량을 요약 과정에서 바꾸지 않는다. 업무범위 밖의 소송·법률 분쟁 대리 등을 암시하지 않는다.
- 자연 초안 → 법률·사실 → 채널 적합성과 과장·홍보 금지 → 윤문 → 의미 재검증의 **기존 단일 검수 흐름**을 따른다. 플랫폼 전용 점수표·강제 사례 개수·추가 검수 단계를 만들지 않는다.
- AI 초안·요약·이미지 생성 자체는 정책상 가능하나 작성자가 사실성·저작권·정확성에 책임을 진다. 허위 전문가 인사이트와 조작 미디어는 금지다.

## 6. 배포·측정

1. 사용자가 커넥트 게시글을 요청하면 docs/sns-authoring-spec.md와 이 문서, 승인 원문이 있는 경우 해당 블로그를 읽는다. 플랫폼 정책 변경이 중요한 작업이면 공식 커넥트 정책을 확인한다.
2. 내용 검수가 끝난 게시문은 기본적으로 한국어 plain-text **.txt 파일**로 제공한다. 채팅 직접 출력을 요청받으면 실제 빈 줄이 있는 복사 가능한 일반 텍스트로 제공한다. 파일을 만들지 못했을 때 가짜 다운로드 링크를 쓰지 않는다.
3. 동일 content_id를 사용해 내부 배포 기록에 채널=remember_connect, 언어, 원본, 실제 게시일, 실제 게시물 URL(확인된 경우), 선택 주제(실제 선택한 경우), 관련 근거 및 게시물별 목적을 남긴다. 기존 배포 파일·시트 구조가 있다면 그 구조를 우선하고 임의의 새 필드를 강제하지 않는다.
4. 실제 계정에서 확인 가능한 반응·유의미한 실무 대화·연결·적합 문의를 구분해서 기록한다. 조회·좋아요를 수임 성과로 환산하지 않고 타인 정보 스크래핑이나 반응 조작을 하지 않는다.
5. 반복 게시 횟수나 발행 시간을 강제하지 않는다. 기존 글의 단순 재게시나 삭제 후 재업로드로 피드를 점유하지 않는다.

## 7. 발행 전 확인

- 이번 글만 읽어도 독자가 자신의 업무 문제와 직접 답, 확인할 자료를 이해하는가?
- 실제 근거·숫자·조건·예외와 작성자 신분·업무범위를 정확히 지켰는가?
- 실명 개인의 업무상 통찰로 읽히고, 무승인 기업 광고·유료 자문 섭외·무료 검토 CTA·우회 링크가 없는가?
- 현재 보이는 리멤버 주제 중 핵심 질문·업종과 가장 밀접한 하나를 골랐으며, 근거 없는 알고리즘 예측에 의존하지 않았는가?
