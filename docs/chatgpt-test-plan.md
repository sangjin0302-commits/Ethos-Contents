# ChatGPT 통합 테스트 안내 (2026-10 개편 후 1회)

목적: 이번 개편(마스터 v7.0, 작성 명세, 문장 예시집, 영문 표현집, 윤문 힌트, v2 레이아웃)이 ChatGPT 산출물에 실제로 반영되는지 한 번에 확인한다. 테스트 결과물은 발행하지 않는다.

## 0. 준비 (한 번)

1. 개편 PR이 main에 머지됐는지 확인한다. ChatGPT의 GitHub 연결은 main을 읽는다.
2. ChatGPT 프로젝트 지침 칸에 `PROJECT_INSTRUCTIONS.md` 내용을 **새로 붙여 넣는다**. 지침 칸은 자동으로 갱신되지 않는다.
3. 프로젝트 파일에 예전 지침 사본(마스터 v6.8 등)이 올라가 있으면 지운다.

## 2. 바로 볼 것 (5분)

| 항목 | 좋은 신호 | 나쁜 신호 |
|---|---|---|
| 읽은 파일 | MANIFEST → 작성 명세 → 예시집을 읽었다고 말함 | 마스터 v6.8, 인라인 CTA 2회, 연락처를 언급 |
| 문장 결말 | 소제목 결론이 "먼저 볼 것은 ~" 같은 기준 | "~해서는 안 됩니다"가 소제목마다 반복 |
| 접속어 | "따라서"가 글 전체에 3~4번 이하 | "따라서/즉/중요한 것은"이 문단마다 |
| CTA | 후반 한 번, 받을 자료와 확인 결과가 구체적 | 중간·말미 반복, "무료 상담" |
| 카드 표지(B) | 제목 2줄 안, 대상과 문제가 바로 보임 | 3줄 이상, 조문 번호 |
| 카드 리듬(B) | 글이 적은 쉼 카드 한 장 이상, 결론 띠 어미가 섞임 | 10장 모두 상자+결론 띠, "~아닙니다" 연속 |
| 영문(B·C) | self-rating platform, local representative 같은 쉬운 표현 | independent-rating business entity 같은 직역 |
| 막힘 | 자연 초안을 끝까지 쓰고 점검표는 짧게 | 규칙 확인만 길고 글이 짧거나 안 나옴 |

## 3. 저장소로 확인 (테스트 B)
