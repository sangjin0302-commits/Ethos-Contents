# 근거 잠금 요약 (Evidence Gate 한 장)

이 파일은 전 매체·언어의 근거 선택·검증 기준이다. 새 법률 주제를 쓰는 경로 B(`docs/blog-authoring-spec.md`)에서는 **이 파일 하나만** 읽는다. 경로 A는 기존 research의 관련성과 변경 여부를, 경로 C는 승인 원문의 근거·판단 이유를 재사용하며 각 빠른 명세의 요약으로 실행할 수 있다. `guidelines/core/top-level.md`, `definitive-style.md`, `docs/legal-verification.md`의 필요한 부분만 간추린 것이다. 충돌하거나 더 자세한 내용이 필요하면 원문이 우선이며, 그때만 원문을 연다.

## 1. 무엇을 어디서 확인하나

### 초안 전에 질문에 맞는 실제 근거를 선택한다

- 중심 질문에 직접 관련된 판결·재결·공식 질의회신·통계·보도·행정자료를 우선 검토한다. 기존 research와 승인 원문에서 출발하며 확인된 근거를 처음부터 다시 찾지 않는다. 새로운 질문이나 변경으로 생긴 공백만 추가 조사한다.
- 적합한 자료가 있으면 사건의 쟁점·판단 이유, 공식 서식의 항목, 통계의 비교 등으로 설명을 이끈다. 본문 끝 출처 목록만으로 적용을 완료하지 않는다. 등록서류 글은 공식 서식·기관 안내가, 처분 판단 글은 관련 판결·재결이 중심이 될 수 있다. 자료 종류별 최소 개수는 만들지 않는다.
- 적합성은 질문과의 직접 관련성, 실제 적용 시점·주체·조건, 확인 가능한 원문을 보고 판단한다. 보도는 사건·수요 맥락으로 쓰되 법률 결론은 공식 원문과 대조하고, 통계는 조사기간·대상·단위·비교 가능성을 보존한다. 공식 질의회신도 질문의 사실관계와 답변 범위를 일반 법규처럼 확대하지 않는다.
- 적합한 사건자료가 없으면 검증된 법령·공식 안내로 설명한다. 관련 없는 판례나 통계를 끼워 넣거나 찾지 못한 사건을 창작하지 않는다. 미확인 자료를 '없음'으로 단정하지 않는다.
- 기존 `research/<시리즈>.md`의 관련 항목이나 변경 이력에 확인한 자료·판본·채택 또는 제외 이유를 필요한 만큼만 남긴다. 매번 별도 보고서나 빈 종류별 표를 만들지 않는다. 파생은 승인 원문의 선택을 재사용하고 새 근거·장면이 필요하면 원문 보강·검증·승인을 먼저 한다.

### 확인할 원문


법률·제도·절차·기관·비용·기한·벌칙·통계는 작성 시점의 공식 1차 자료로 확인한다.

1. 법령·시행령·시행규칙·고시·행정규칙(국가법령정보센터 law.go.kr 현행 본문)
2. 판결문, 재결례·결정례, 공식 질의회신 원문
3. 정부·공공기관 공식 안내와 통계
4. 학술논문·전문 연구보고서
5. 신뢰도 높은 보도·전문기관 분석
6. 블로그·커뮤니티·SNS: 질문·수요·표현을 찾는 데만 쓴다. 핵심 법률 결론의 단독 근거로 쓰지 않는다.

- 시행 예정 개정이 있으면 현행 조문과 시행 예정 조문을 구분한다.
- 판례는 법원명·사건번호·선고일, 재결례는 기관명·의결번호·의결일까지 확인한다. 확인하지 못한 것은 쓰지 않는다.
- 모든 글의 내부 research/검수 기록에 **확인 기준일**과 판본을 적는다. 내부 확인 기록 없는 법률·제도 문장은 발행하지 않는다. 공개 본문·캡션의 독립 확인 기준일 라벨은 제외하되 법령 시행일·판결일·통계기간은 보존한다.
- 법령 조회 도구가 없으면 쓴 것처럼 말하지 않고, 사람이 공식 사이트에서 확인할 조문 목록을 완성본 뒤에 붙인다.
- 같은 시리즈에서 이미 확인한 근거는 `research/<시리즈>.md`를 재사용하고 기준일 이후 변경만 본다(`research/README.md`).

## 2. 증거 라벨(내부 점검용, 원고에 노출하지 않는다)

F 확인된 사실 / I 확인된 사실에서 나온 추론 / S 설명용 가상 시나리오 / U 미확인(발행 금지)

실제 사건의 사실·인용과 설명용 예시를 섞지 않는다. 실제 사건에 원문에 없는 대화·감정·피해액·결과를 붙이거나 재구성한 말을 당사자·공무원의 발언으로 인용하지 않는다. 다양한 예시 인물과 짧은 대화는 문맥에서 예시임을 드러내어 쓸 수 있으나 대사 자체는 근거가 아니며 오해는 이어지는 설명에서 바로잡는다.

## 3. 문체

- F는 단정한다(`~합니다`, `~해야 합니다`, `~할 수 없습니다`). 조건이 있으면 조건을 먼저 밝히고 결론을 단정한다.
- 질문에 답할 근거가 있으면 첫 답변 문장에서 맞는지·가능한지를 분명히 한다. 근거는 그다음에 쓴다.
- `이것도 맞고 저것도 맞습니다` 식으로 결론을 피하지 않는다. 실제로 조건에 따라 달라지면 `A 조건이면 X, B 조건이면 Y`와 지금 확인할 조건을 쓴다.
- I는 `~로 볼 수 있습니다`로 한정하고, S는 예를 들어·조건형 도입 등 문맥에서 예시임을 드러낸다. 다양한 이름·짧은 예시 대화는 허용하며 독립 가상 고지문은 넣지 않는다. 허구를 실제 상담·수임·후기·성과로 주장하거나 기관 인용을 만들지 않는다.
- 유보가 허용되는 경우: 사실관계에 따라 결론이 달라질 때, 행정청 재량일 때, 예외 적용이 확정되지 않았을 때, 공식자료로 개별 결론을 확정할 수 없을 때.
- 하지 않는다: 사실을 확인하고도 문장마다 `~할 수 있습니다`를 붙이기, 결과 보장, 조건·예외를 지워 강하게 만들기, 마케팅을 이유로 법률 의미를 넓히거나 좁히기. 법률상 `할 수 있다`(권한·재량)를 `한다`로 기계적으로 바꾸지 않는다.

## 4. 콘텐츠에서 걸리는 행정사법 조항(발행 전 현행 본문 재확인)

| 조항 | 점검할 것 |
|---|---|
| 제22조 제5호 | 거짓·과장·누락 광고 금지. 성공률·처리 건수·"최고", 확인되지 않은 수치를 쓰지 않는다 |
| 제22조 제4호 | 공무원과의 연고 등 영향력 선전 금지. 담당자 친분·"심사자 시각"을 영향력 암시로 쓰지 않는다 |
| 제22조 제3호 | 업무범위 밖 소송·분쟁·민원 개입 금지. 법정 범위를 넘는 대리를 약속하지 않는다 |
| 제23조 | 직무상 알게 된 사실 누설 금지. 익명화해도 개별 사안이 특정되면 쓰지 않는다 |
| 제15조 | 사무소 명칭 표기. 사무소 형태를 사실과 다르게 연출하지 않는다 |
| 제21조 | 품위·성실 의무. 공포·긴박감 조작, 다른 자격사 비하 금지 |

다른 자격사(변호사·법무사·세무사·노무사)의 업무 영역 문장은 해당 자격사법 조문으로 따로 확인한다.

## 5. 반복되는 위험 표현

- "처리했다", "다뤄 본" 같은 경험 서술은 실제 있었던 일만. 후기·건수·성과를 만들지 않는다.
- "무료 상담" 금지. 무료 검토의 범위는 `docs/brand-philosophy.md` 6절(웹사이트 운영정책이 정본)을 넘기지 않는다.
- "A는 B만 하면 된다"처럼 조건·예외를 지우지 않는다. 원문의 "또는/그리고/~할 수 있다"를 그대로 둔다.

## 6. 인용 검증

승인 요청 전에는 선택한 원문과 본문의 주체·조건·예외·의무/재량·숫자·인용 및 판단 이유를 대조한다. 자동 인용 검사는 조문·별표·판례·재결 번호의 존재와 표기 대조에 한정되며 해석의 정확성을 보증하지 않는다. PR을 올리면 `Verify citations` 워크플로가 조문을 자동 대조해 댓글로 남긴다. 커넥터가 있으면 `verify_citations`, 없으면 국가법령정보센터에서 하나씩 조회하고, 도구를 쓰지 않았으면 쓴 것처럼 적지 않는다. 확인하지 못한 항목은 사용자에게 알린다.
