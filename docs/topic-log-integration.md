# 글감관리표 기반 소재 선정

글감관리표는 아이디어 목록이 아니라 발행 이력과 실제 반응을 연결하는 운영 자료다. 소재를 새로 정할 때 docs/topic-discovery.md와 함께 사용한다. 조회수가 높은 제목을 그대로 반복하지 않고, 어떤 문제에서 검색·재방문·문의가 생겼는지 확인해 다음 판단 질문으로 확장한다.

## 입력 자료

기본 파일은 에토스_글감관리표.xlsx다. ChatGPT 프로젝트 소스, Google Drive 연결 파일 또는 사용자가 제공한 최신 파일을 읽는다. 원본 표는 수정하지 않는다.

### 소재 관리(블로그 기준)

- 소재명
- 영역
- 상태
- 발행일

제목이 없는 예약 행이나 서식만 남은 빈 행은 후보로 사용하지 않는다. 발행완료는 중복 확인과 최신화 판단에 사용하고, 기획은 제목과 근거가 실제로 입력된 행만 신규 후보로 사용한다.

### 주간 성과

- 기준주, 조회수, 재방문율, AI 인용 누적
- TOP1~TOP3 제목과 조회수
- 문의 건수와 유입글
- 업무군별 체크, 메모

조회수와 AI 인용은 관심 신호일 뿐 수임·전문성의 증거로 확대하지 않는다. 문의 유입글이 기록되어 있으면 조회수보다 우선하되, 개인정보와 상담 내용을 소재로 옮기지 않는다.

## 후보 만들기

표를 읽은 뒤 후보를 다음 네 유형으로 나눈다.

1. **확장**: 여러 주에 반복해서 TOP3에 든 기존 글을 더 구체적인 조건·문서·순서 질문으로 확장한다.
2. **전환**: 실제 문의 유입글과 연결된 주제를 Reader Boundary, Proof of Work, 구체적 무료 검토 항목이 있는 글로 보강한다.
3. **최신화**: 발행 후 법령·고시·기관 안내가 바뀌었거나 재검토일이 지난 글을 갱신한다.
4. **공백 보완**: 성과가 좋은 Entry 주제와 연결되지만 아직 없는 Core·Composite·Recurring B2B 질문을 만든다.

같은 제목의 후속편을 기계적으로 만들지 않는다. 분류 경계·제도 교차·순서 의존성·문서 정합성·기관 분산·보완 가능성·반복성·국제화 마찰 가운데 새로운 판단 긴장이 있어야 한다.

## 우선순위 점수

점수는 발행을 막는 하드 게이트가 아니라 후보 비교용이다.

| 항목 | 점수 | 판단 기준 |
|---|---:|---|
| 문의 연결 | 0~25 | 유입글 또는 밀접한 후속 질문이 실제 문의와 연결됐는가 |
| 반복 관심 | 0~20 | 여러 주 TOP3, 재방문 또는 저장·공유 신호가 반복됐는가 |
| 희소성과 브랜드 적합 | 0~20 | 희소성 신호와 신사업 인허가·국제화 축이 만나는가 |
| 전환 가능성 | 0~15 | 받을 자료와 확인 결과를 구체적으로 제시할 수 있는가 |
| 최신성 필요 | 0~10 | 제도 변경 또는 장기 미갱신 때문에 다시 확인할 가치가 있는가 |
| 포트폴리오 공백 | 0~10 | Entry에서 Core·Composite·Recurring B2B로 이어지는 빈칸을 채우는가 |

다음 경우에는 점수와 무관하게 보류한다.

- 공식 1차 자료로 확인할 수 없는 주제
- 기존 글과 판단 질문이 실질적으로 같은 주제
- 경험담·수임 성과·고객 반응을 만들어야만 성립하는 주제
- 현재 자격과 업무 범위를 넘어서는 결론을 요구하는 주제

## 선정 결과 기록

선정한 소재는 brief.md에 다음을 남긴다.

- 어떤 표와 어느 기간을 확인했는지
- 신규·확장·최신화·재가공 가운데 무엇인지
- 반복 관심과 문의 연결 근거
- 기존 글과 달라지는 판단 질문
- 상위 허브, 이전 글, 다음 글, CTA 경로
- 확인일, 갱신 조건, 재검토 예정일

성과표가 없거나 최신 상태를 확인하지 못하면 그 사실을 적고 docs/topic-discovery.md의 질적 기준으로 진행한다. 표가 없다는 이유로 콘텐츠 생성을 중단하지 않는다.
