# 글감관리표 기반 소재 선정

글감관리표는 아이디어 목록이 아니라 발행 이력과 실제 반응을 연결하는 운영 자료다. 소재를 새로 정할 때 docs/topic-discovery.md와 함께 사용한다. 조회수가 높은 제목을 그대로 반복하지 않고, 어떤 문제에서 검색·재방문·문의가 생겼는지 확인해 다음 판단 질문으로 확장한다.

## 입력 자료

기본 파일은 에토스_글감관리표.xlsx다. ChatGPT 프로젝트 소스, Google Drive 연결 파일 또는 사용자가 제공한 최신 파일을 읽는다. 원본 표는 수정하지 않는다.

### 소재 관리(블로그 기준)

- 소재명
- 영역
- 상태
- 발행일

제목이 없는 예약 행이나 서식만 남은 빈 행은 후보로 사용하지 않는다. 발행완료는 중복 확인과 최신화 판단에 사용하고, 기획은 제목과 근거가 실제로 입력된 행만 신규 후보로 사용한다.

### 주간 성과

- 기준주, 조회수, 재방문율, AI 인용 누적
- TOP1~TOP3 제목과 조회수
- 문의 건수와 유입글
- 업무군별 체크, 메모

조회수와 AI 인용은 관심 신호일 뿐 수임·전문성의 증거로 확대하지 않는다. 문의 유입글이 기록되어 있으면 조회수보다 우선하되, 개인정보와 상담 내용을 소재로 옮기지 않는다.

## 검색수요 증거를 먼저 붙이기

신규 시리즈 또는 글감 묶음을 정할 때 `docs/sustainable-growth-system.md`의 검색수요 증거 카드를 작성한다. 최소한 검색어 묶음, 확인일, 비교기간, 상대 추세, 실제 노출·클릭 여부, 내부 문의 신호, 판단과 재검토일을 남긴다.

- 네이버 데이터랩 ratio는 절대 검색량이 아니라 비교기간 내 상대값으로 기록한다.
- 네이버 서치어드바이저는 웹사이트 웹 검색 데이터이며 VIEW·블로그 검색 전체 수요로 확대하지 않는다.
- 도구별 숫자는 범위와 지연이 달라 서로 합산하지 않는다.
- 검색수요가 높고 문의가 아직 없으면 버리지 않고 Entry 역할과 Core·Revenue 연결을 먼저 점검한다.
- 화장품 시리즈는 검색수요 확인 뒤 편성된 기준 사례로 취급하며 예정 발행을 유지한다.

## 후보 만들기

표를 읽은 뒤 후보를 다음 네 유형으로 나눈다.

1. **확장**: 여러 주에 반복해서 TOP3에 든 기존 글을 더 구체적인 조건·문서·순서 질문으로 확장한다.
2. **전환**: 실제 문의 유입글과 연결된 주제를 Reader Boundary, Proof of Work, 구체적 무료 검토 항목이 있는 글로 보강한다.
3. **최신화**: 발행 후 법령·고시·기관 안내가 바뀌었거나 재검토일이 지난 글을 갱신한다.
4. **공백 보완**: 성과가 좋은 Entry 주제와 연결되지만 아직 없는 Core·Composite·Recurring B2B 질문을 만든다.

같은 제목의 후속편을 기계적으로 만들지 않는다. 분류 경계·제도 교차·순서 의존성·문서 정합성·기관 분산·보완 가능성·반복성·국제화 마찰 가운데 새로운 판단 긴장이 있어야 한다.

## 우선순위 점수

점수는 발행을 막는 하드 게이트가 아니라 후보 비교용이다.

| 항목 | 점수 | 판단 기준 |
|---|---:|---|
| 검증된 검색수요 | 0~25 | 상대 추세와 실제 노출·클릭 등 둘 이상의 신호가 있는가 |
| 문의 연결 | 0~25 | 유입글 또는 밀접한 후속 질문이 실제 문의와 연결됐는가 |
| 반복 관심 | 0~15 | 여러 주 TOP3, 재방문 또는 저장·공유 신호가 반복됐는가 |
| 희소성과 브랜드 적합 | 0~15 | 희소성 신호와 신사업 인허가·국제화 축이 만나는가 |
| 전환 가능성 | 0~10 | 받을 자료와 확인 결과를 구체적으로 제시할 수 있는가 |
| 최신성 필요 | 0~5 | 제도 변경 또는 장기 미갱신 때문에 다시 확인할 가치가 있는가 |
| 포트폴리오 공백 | 0~5 | Entry에서 Core·Composite·Recurring B2B로 이어지는 빈칸을 채우는가 |

다음 경우에는 점수와 무관하게 보류한다.

- 공식 1차 자료로 확인할 수 없는 주제
- 기존 글과 판단 질문이 실질적으로 같은 주제
- 경험담·수임 성과·고객 반응을 만들어야만 성립하는 주제
- 현재 자격과 업무 범위를 넘어서는 결론을 요구하는 주제

## 선정 결과 기록

선정한 소재는 brief.md에 다음을 남긴다.

- 어떤 표와 어느 기간을 확인했는지
- 신규·확장·최신화·재가공 가운데 무엇인지
- 반복 관심과 문의 연결 근거
- 기존 글과 달라지는 판단 질문
- 상위 허브, 이전 글, 다음 글, CTA 경로
- 확인일, 갱신 조건, 재검토 예정일

성과표가 없거나 최신 상태를 확인하지 못하면 그 사실을 적고 docs/topic-discovery.md의 질적 기준으로 진행한다. 표가 없다는 이유로 콘텐츠 생성을 중단하지 않는다.

## 마케팅 점검 (주간 성과 탭)

마케팅·성과 분석, 채널·시리즈·표지 방향을 정할 때도 이 표의 **주간 성과** 탭을 기준 자료로 쓴다. 아래 값을 직접 계산해 숫자로 보고한다. 표를 읽지 못했으면 읽은 것처럼 말하지 않는다.

| 지표 | 계산 | 보는 이유 |
|---|---|---|
| 조회 추세 | 최근 3주 평균 ÷ 직전 최고 3주 평균 | 유입이 늘고 있는지 |
| 문의 전환 | 기간 문의 건수 ÷ 기간 조회수 | 조회가 문의로 이어지는지 |
| 문의 유입 주제 | 유입글을 영역(비자·인허가·행정심판·법인·계약·강연)으로 묶어 건수 | 무엇이 실제 문의를 만드는지 |
| 조회 상위 주제 | TOP1~3에 두 주 이상 든 주제와 영역 | 무엇이 관심을 끄는지 |
| 관심과 문의의 어긋남 | 유입글이 기록된 기간에서, 조회 상위 주제 중 유입글로 한 번도 기록되지 않은 주제. 유입글이 빈칸·미상인 문의는 "출처 미상 n건"으로 따로 센다 | 표지·CTA·대상 독자를 고칠 후보 |
| 시리즈 성과 | 시리즈별로 TOP3에 든 편 수. 제목에 시리즈명이 있거나 표에 시리즈 열이 있을 때만 계산하고, 소속을 추측하지 않는다 | 어떤 시리즈 형식이 통하는지 |
| AI 인용 증가 | 주간 증가분, 정체 주 수 | 웹사이트·AI 검색 쪽 성과 |

판단 원칙:
- 문의가 기록된 주제를 조회 상위 주제보다 우선한다. 조회만 높은 주제는 표지·대상 독자·마지막 안내를 고칠 후보다. 출처 미상 문의가 많으면 어긋남 결론을 내리지 않고 출처 기록부터 보완한다.
- 이 탭은 전체 추세와 주제 단위 보조 자료다. 세트별 Primary Objective(저장·프로필 방문 등) 판단은 `performance-log.csv`와 `docs/performance-learning.md`를 따른다.
- 표본이 작다(주당 문의 0~2건). 세 주 이상 같은 방향일 때만 결론으로 쓰고, 그 전에는 가설로 적는다(`docs/performance-learning.md`).
- 결과는 "다음 4주에 바꿀 것 1~3개"로 끝낸다. 예: 생활 장면형 표지를 비자 시리즈에 적용, 강연 직후 관련 글 발행.

표에 다음 열이 있으면 더 정확해진다(원본 표는 사용자가 관리한다): 시리즈명, 문의별 `content_id`와 유입 채널(네이버·웹사이트·인스타·LinkedIn·강연), 카드뉴스 저장 수. 게시물마다 `scripts/tracking_link.py`로 만든 상담 접수 링크를 쓰면 웹사이트 관리자 `/admin/funnel`에 content_id·채널별 문의가 자동으로 쌓인다(`docs/strategy-playbook.md` 5절). 그 값이 있으면 문의 유입 주제·어긋남 계산에 시트의 "유입글"보다 우선해 쓰고, 시트에는 주간 합계만 옮겨 적어도 된다.
