# 카피·구성 지침 (Editorial)

카드뉴스는 검증된 블로그 원문을 **더 빨리 발견·이해·저장하게 하는 시각적 입구**다. 사실과 논리의 기준은 언제나 원문이다.
(근거 자료·학술 인용·KPI 는 이 문서에 넣지 않는다. 필요하면 별도 reference 로 둔다.)

## 1. 원문 잠금
- **FACT LOCK**: 숫자·날짜·조문번호·판례번호·기관명·금액은 원문 표기 그대로. (qa 가 원문 대조)
- **COPY FLEX**: 의미를 유지하는 범위에서만 문구 압축 가능.
- 접속·한정어 보존: 「또는」→「+」, 「할 수 있다」→「한다」, 「일부」→「모든」 금지. 예외가 중요한 문장은 예외를 남긴다.
- 원문에 없는 논리식·등식·화살표 인과를 만들지 않는다. 기호가 꼭 필요하면 brief.md 에서 사람 승인 후 `data-symbol-ok`.
- `출처 입력`·편집 메모·미완성 자리표시는 카피로 쓰지 않는다.
- 카드에 넣는 모든 문장은 card-data.json 의 `sourceTrace` 로 원문 위치를 가리킬 수 있어야 한다.

## 2. 각도와 분량
- 블로그 한 편에서 **각도 하나**만 고른다: 독자가 가장 오해하는 문장 / 문서·절차가 엇갈리는 지점 / 두 개념 대비 / 저장할 판단 기준 / 스스로 확인할 항목.
- 카드 수는 필요한 메시지 수로 정한다(6~10장). 단일 각도면 6~8장이 기본. 장수를 맞추려고 늘리지 않는다.
- 뺀 섹션은 `brief.md` OMITTED 에 기록한다(빠뜨린 게 아니라 뺀 것임을 남긴다).

## 3. Hook (표지)
표지는 설명이 아니라 **알아보게 하는** 장이다. 다음 중 둘 이상: 대상 독자 / 구체적 상황 / 판단해야 할 문제 / 읽고 얻을 정보.
- 후보 3개를 쓰고 하나를 고른다. 이유 한 줄.
- 유형: Scenario(장면) · Question(독자의 질문) · Mistake(흔한 실수) · Distinction(A와 B의 차이) · Consequence(원문에서 확인되는 결과) · Checklist(저장할 점검) · Case(원문 사례의 충돌) · Process(판단 순서).
- 훅 문장이 표지에서 **가장 크다.** 표지 요소는 3개 이하(칩·훅·한 줄 보조).
- 금지: 모르면 손해 / 무조건 / 100% / 충격 / 당장 확인 / 가짜 긴급성 / 결과 보장 / 질문만 던지고 답을 숨기기.
- 물음표·숫자·콜론·대시 자체는 훅이 아니다. 실제 독자 문제와 정보 보상이 선명할 때만 사용한다.

## 4. 서사와 카드 유형
기본 흐름(소재에 맞게 줄이거나 합친다): Cover → Context → Conflict → Principle → Breakdown → Application → Boundary → Action.
- 카드마다 `oneMessage`: "이 장에서 독자가 기억할 것은 ___이다." 한 문장으로 채워져야 한다.
- 다음 장으로 넘어갈 **논리적 이유**를 둔다(상황→충돌→기준→적용→한계). "다음 장에서 공개" 류 금지.
- 2~3장마다 독자가 바로 쓸 정보(판단 기준·비교·확인 순서·체크리스트)를 준다.
- 같은 골격 반복 금지. 개념 대비는 comparison, 순서는 process, 저장용은 checklist를 우선 검토하되, 유형 수를 맞추기 위해 원문을 변형하거나 카드를 추가하지 않는다.
- 한 카드의 독립 영역은 3개 이하. 긴 설명·표·CTA·연락처·면책을 한 장에 몰지 않는다.

## 5. CTA
- CTA 는 연락처를 보여주는 장치가 아니다. 읽은 내용을 자기 상황에 적용하는 **다음 행동 하나**.
- 마지막 두 장: ① 스스로 확인할 수 있는 범위 ② 전문가 검토가 필요한 상황. 마지막 문장은 무료 검토 안내.
- 기본 문장: 「무료 검토를 통해 자신의 상황에서 가능 여부를 확인할 수 있습니다.」(문맥에 맞게만 다듬기)
- 금지: 연락처·URL·카카오톡·텔레그램·이메일·버튼, 연락처 디렉터리, 「무료 상담」, 긴박감 조작, 결과 보장.
- 실제 접수 경로는 게시물 캡션·프로필·홈페이지가 담당한다(카드가 아님).

## 6. Authority (전문성)
- 이력을 소개하지 않고 **판단 방식으로 보여준다**: 조문·판결·공식 자료를 정확히 읽기 / 문서 간 불일치 분석 / 기관별 확인 지점 구분.
- 금지: 「저는 X 출신입니다」, 이력 나열 카드, About me 카드, 「최고·대표·leading」.
- 원문에 근거 없는 전문성 문구를 만들지 않는다.

## 7. 톤
- 구어체·정직·구체적. 법률 정보는 절제된 톤. 과장·공포·손실 프레임 금지.
- 헤드라인은 독자가 겪는 상황을 먼저, 전문용어는 나중에. 헤드라인 2줄 이하(표지 3줄).
- 줄바꿈은 의미 단위(`word-break: keep-all`). 외톨이 한 글자 줄 금지.

## 8. 성과 기록 (발행 후, 사람이 입력)
Content ID · 원본 블로그 · 대상 독자 · 독자 질문 · 실용적 보상 · Hook 유형 · 카드 수 · 출력 비율 · CTA 입력자료·확인결과 · 제작 시간 · 채널별 지표(마지막 장 도달·저장·공유·프로필 방문·무료 검토 요청·적합 문의). 한 번에 변수 하나만 바꿔 비교하고, 표본이 적으면 규칙을 확정하지 않는다. 자동 마케팅 점수보다 실제 행동 데이터를 우선한다.
