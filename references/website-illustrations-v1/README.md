## Reference and image handling

- Approved art direction: premium minimal editorial; cream and navy with fine gold path accents; 4:3 composition; no AI character mascot.
- Original generated masters: PNG, 1448 × 1086. The image bundle and exact SHA-256 fingerprints are delivered separately with this reference registration; **do not treat reduced-size previews as production masters**.
- These are **AI-generated conceptual images**, not verified photographs of an office, case, client, actual legal document or successful outcome. Do not imply otherwise.
- Brand source: `brand/tokens.json` — navy `#1B2B6B`, deep navy `#152056`, gold `#B8972A`, cream `#F5F0E8`.
- The original artwork uses light, texture, shadows and secondary hues. **A pixel-exact recolor to the card-news HEX values is not required.** Only correct visually discordant tones after comparing screenshots of the actual website.
- Deployment work belongs in the website repository after responsive-layout, accessibility, file-size and mobile-crop review.
- Preserve existing card-news output unchanged.
