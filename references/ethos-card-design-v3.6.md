# 에토스 카드뉴스 디자인·성과 운용지침 v3.6

### Evidence-first · Reader-payoff · Adaptive composition

> 적용 대상: 검증된 원문에서 파생하는 한국어·영어 ETHOS BRIEF 카드뉴스
>
> 이 문서는 카드뉴스의 기획·마케팅 판단·편집 구성·성과학습을 규정한다. 결정론적 렌더링, 로컬 폰트, 디자인 토큰, 공통 프레임, Fact Lock과 기계 QA의 상세 기준은 `ethos-card-design-v3.3.md`를 함께 따른다.

## v3.6 핵심 변경

1. 카드 유형 수와 `checklist`·`process` 사용을 하드 게이트에서 편집 권고로 전환한다.
2. 물음표·콜론·인용 카드의 존재만으로 훅이나 신뢰 점수를 올리지 않는다.
3. 표지는 독자·문제·읽고 얻는 결과가 선명한지를 중심으로 평가한다.
4. 저장가치는 특정 카드 유형이 아니라 다시 확인할 실용 정보가 있는지로 평가한다.
5. CTA는 실제로 받을 자료와 실제로 확인할 결과가 맞물리는지 평가한다.
6. 마케팅 점수는 발행 합격점이 아니라 약한 부분을 찾는 진단값으로만 사용한다.
7. Golden Reference 회귀 검사는 공통 프레임과 대표 템플릿에만 적용하고, 새 콘텐츠의 창의성을 픽셀 일치로 제한하지 않는다.
8. 노출보다 저장·공유·프로필 방문·무료 검토 요청·수임 연결을 우선해 성과를 학습한다.

# PART 0. 우선순위와 게이트

충돌 시 다음 순서로 적용한다.

1. 사용자의 현재 요청
2. 최신 프로젝트 최상위 지침과 법률·CTA 정책
3. 승인된 원문과 카드별 Source Trace
4. 이 지침 v3.6
5. 결정론적 제작 표준 v3.3
6. 개별 Build Spec과 Golden Reference

## 0-1. 하드 게이트

다음 항목은 실패하면 렌더링 또는 납품을 중단한다.

- 원문에 없는 사실·숫자·조문·사례 추가
- 중요한 조건·예외·주체의 의미 변경
- 사용자 승인 누락
- 국문·영문 사실 구조 불일치
- 필수 폰트·프레임·캔버스·출력 크기 불일치
- 오버플로·클리핑·금지 문구·허용되지 않은 외부 호출
- 필수 Source Trace 누락

## 0-2. 편집 권고

다음 항목은 경고와 사람 검토 대상으로만 사용한다.

- 카드 유형의 수와 배합
- `checklist` 또는 `process` 사용 여부
- 헤드라인 글자 수와 줄 수
- 본문 채움 비율과 여백의 양
- 카드별 텍스트 예산
- 시각적 변주와 배경 리듬
- 마케팅 진단 점수

권고 점수를 올리기 위해 사실, 한정어, 예외 또는 자연스러운 구성을 희생하지 않는다.

# PART 1. 원문과 한 게시물의 약속

## 1-1. Source Lock

승인된 블로그 원문 또는 Source Brief를 사실과 논리의 단일 기준으로 삼는다. 모든 카드 문장은 `sourceTrace`로 원문 위치를 가리킬 수 있어야 한다.

## 1-2. 한 게시물의 약속

제작 전에 다음 네 항목을 한 문장씩 확정한다.

- `targetReader`: 지금 어떤 상황에 있는 독자인가
- `readerQuestion`: 독자가 해결하려는 질문은 무엇인가
- `primaryObjective`: 발견·이해·저장·공유·신뢰·검토 중 무엇인가
- `practicalPayoff`: 끝까지 보면 무엇을 판단하거나 준비할 수 있는가

한 세트는 하나의 핵심 질문과 하나의 주된 행동을 다룬다. 긴 원문 전체를 축소해 넣지 않는다.

# PART 2. 표지와 전개

## 2-1. 표지

표지는 2초 안에 다음 세 가지 중 최소 두 가지를 전달해야 한다.

- 누구의 문제인가
- 무엇을 판단해야 하는가
- 읽고 나면 무엇을 알 수 있는가

질문부호, 숫자, 콜론, 대시 자체는 훅이 아니다. 독자의 실제 상황을 구체화할 때만 사용한다.

금지:

- 답을 숨기는 가짜 궁금증
- 실제 근거가 없는 손실·긴급성
- `무조건`, `100%`, `충격`, `모르면 손해`
- 질문만 있고 정보 보상이 없는 표지

## 2-2. 전개

권장 흐름은 `상황 → 충돌 또는 오해 → 판단 기준 → 적용 → 경계 → 다음 행동`이다. 소재에 맞게 줄이거나 합칠 수 있다.

- 카드 한 장에는 기억할 메시지 하나만 둔다.
- 다음 장으로 넘길 이유는 새로운 판단 정보여야 한다.
- `다음 장에서 공개` 같은 인위적 긴장은 쓰지 않는다.
- 2~3장 안에는 비교·순서·확인 항목 등 실제 정보 보상이 있어야 한다.
- 카드 유형은 내용에 맞게 선택한다. 유형 수를 맞추기 위해 내용을 변형하지 않는다.

# PART 3. 저장·공유·신뢰

## 3-1. 저장가치

저장가치는 `checklist`나 `process` 카드의 존재가 아니라 다음 중 하나를 다시 확인할 필요가 있는지로 판단한다.

- 판단 기준
- 준비 순서
- 문서 간 대조 항목
- 직접 확인할 사항
- 전문가 검토가 필요한 경계

## 3-2. 공유가치

공유를 유도하는 문구를 넣는 대신, 특정 사업자·외국인·계약 당사자에게 전달할 이유가 분명한 정보를 제공한다.

## 3-3. Authority Demonstrate

이력을 주장하지 않고 다음과 같은 판단 작업으로 전문성을 보여준다.

- 조문·판례·공식자료의 표현 차이
- 계약서·사유서·신청서 등 문서 간 불일치
- 기관별 확인 지점과 절차 순서
- 일반론으로 결론 내릴 수 없는 경계

인용 카드가 있다는 사실만으로 신뢰가 생기지 않는다. 인용의 출처와 해설이 독자의 판단을 실제로 바꿀 때만 사용한다.

# PART 4. Reader Boundary와 CTA

마지막 부분에서는 다음을 구분한다.

1. 독자가 공식 안내와 보유 자료로 직접 확인할 수 있는 범위
2. 여러 법령·기관·문서가 얽혀 개별 검토가 필요한 상황

CTA는 한 번만 사용한다. 연락처·URL·버튼은 카드에 넣지 않는다.

CTA를 만들기 전에 다음을 확정한다.

- `ctaInputs`: 독자가 실제로 제공할 자료 또는 사실 1~3개
- `ctaOutcomes`: 무료 검토에서 실제로 확인해 줄 결과 1~3개

입력자료와 확인결과가 카드 주제와 직접 연결되어야 한다. 결과 보장, 무료 범위 확대, 긴급성 조작은 금지한다. 마지막 문장은 독자가 자신의 상황에서 가능 여부를 확인할 수 있도록 무료 검토를 안내한다.

---

# PART 5. 비주얼 운용

- 공통 워드마크·프레임·색상·로컬 폰트는 유지한다.
- 한 장에는 하나의 시각적 중심을 둔다.
- 같은 박스 구성을 연속 반복하지 않는다.
- 사진·삽화는 설명력을 높일 때만 사용하며 텍스트를 생성 이미지에 맡기지 않는다.
- 법률·행정 콘텐츠라는 이유로 모든 카드를 문서처럼 만들지 않는다.
- 장식보다 정보 위계, 모바일 가독성, 카드 간 리듬을 우선한다.

## 5-1. Golden Reference

Golden Reference는 브랜드 프레임과 품질 하한을 지키는 기준이다. 새 콘텐츠를 기존 카드와 픽셀 단위로 똑같이 만드는 템플릿은 아니다.

시각 회귀 검사는 다음에 적용한다.

- 공통 헤더·푸터·골드바
- 안전영역과 기본 타이포그래피
- 대표 카드 유형의 템플릿
- 의도하지 않은 위치·크기·색상 변화

콘텐츠마다 달라지는 문장 길이, 카드 유형 조합, 의도적 레이아웃 변주는 사람의 축소 시트 검수로 판단한다.

# PART 6. 마케팅 진단과 성과학습

## 6-1. 진단 원칙

자동 마케팅 평가는 다음 다섯 축의 약한 부분을 찾는다.

- Hook: 대상·문제·정보 보상의 선명도
- Trust: Source Trace·근거·한정어·과장 통제
- Readability: 한 장 한 메시지·밀도·모바일 가독성
- Utility: 다시 볼 판단 기준이나 준비 정보
- Conversion: 입력자료와 확인결과가 구체적인 다음 행동

총점은 발행 허가나 성과 예측값이 아니다. 개별 축의 권고를 먼저 본다.

## 6-2. 실제 성과 우선순위

발행 후에는 가능한 범위에서 다음 순서로 기록한다.

1. 무료 검토 요청과 적합한 문의
2. 프로필·홈페이지 이동
3. 저장과 공유
4. 완독 또는 마지막 장 도달
5. 노출과 좋아요

표본이 적을 때 규칙을 확정하지 않는다. 한 번에 훅, 카드 수, 비주얼 패밀리, CTA 중 한 변수만 바꿔 비교한다.

---

# PART 7. 완료 기준

완료는 다음을 모두 만족한 상태다.

- 하드 게이트 통과
- 국문·영문 Source Trace와 사실 구조 일치
- 폰 크기 축소 시트에서 핵심 메시지 확인 가능
- 표지가 대상과 문제를 즉시 전달
- 정보 보상이 존재
- 직접 확인 범위와 전문가 검토 경계가 구분됨
- CTA가 실제 서비스 범위와 일치
- 사람 검수 항목 전달 완료

> 좋은 카드뉴스는 규칙의 개수를 보여주는 결과물이 아니라, 검증된 판단을 짧은 시간 안에 이해시키고 다음 행동을 분명하게 만드는 결과물이다.
