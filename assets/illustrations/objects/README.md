# 물건 일러스트 (Phosphor Icons duotone, MIT)

- 원본: Phosphor Icons 2.1.1(`@phosphor-icons/core`, `assets/duotone/`), MIT(`LICENSE-phosphor.txt`), 2026-10-06
- 수정: 색만 바꿨다. 원본의 옅은 층(opacity 0.2)을 브랜드 골드 면(`--obj-fill`, 기본 `--ethos-gold`)으로, 선은 `currentColor`로 둔다. 도형은 그대로.
- 프리셋 A가 배경에 맞춰 선 색을 정한다: 네이비 카드는 크림 선, 크림 카드는 네이비 선. 사람 그림보다 사무소 톤에 맞고 네이비 표지에도 쓸 수 있다.

|---|---|

| 서류 | file-text, file-magnifying-glass, clipboard-text, envelope-simple-open, receipt, scroll, folder-open |
| 기한 | calendar-x, calendar-check, hourglass-medium |
| 체류·비자 | identification-card, airplane-tilt |
| 사업·장소 | storefront, building-office, house-line, briefcase, bank, truck, bowl-food, laptop |

쓰는 법: SVG를 카드 HTML에 붙이고 `.obj-hero`(큰 그림 하나) 안에 둔다. `assets.md`에 `phosphor/<이름>`과 MIT를 적는다. 한 카드에 하나, 표지나 쉼 카드의 시각 중심으로 쓴다.
