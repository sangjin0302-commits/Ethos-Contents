# ETHOS Art Direction

기존 브랜드를 특정 작업물에 적용하는 스킬이다. `docs/card-design-guide.md`, `docs/card-codex-production.md`, `docs/asset-policy.md` 및 해당 승인 원문·brief를 먼저 확인한다. 공통 운영은 `docs/writing-design-skills.md`를 따른다. 새 브랜드 정의나 일반 본문 카드의 최소문자화를 하지 않는다.

## 가벼운 시각 브리프

기존 `brief.md` 또는 허용된 카드 `design` 메모에 아래 필요한 항목만 보강한다. 새 필수 JSON 필드나 별도 긴 보고서를 만들지 않는다.

1. **핵심 질문과 근거.** 독자가 알아야 할 차이·순서·조건을 한 문장으로 정하고 승인 원문의 해당 구절을 대응시킨다. Source Lock: 원문에 없는 문서·사례·법률 관계·성과·권위를 이미지로 추가하지 않는다.
2. **보여줄 관계.** 실제 두 문서의 차이는 대조, 실제 단계는 흐름, 실제 조건은 분기로 표현한다. 관계가 없으면 억지 화살표·숫자 차트·도식을 만들지 않는다. '고급스럽게' 대신 시선의 시작, 시각 중심 하나, 정보 묶음, 여백과 피할 구도를 구체화한다.
3. **제작 조건.** ETHOS 색·글꼴·프레임과 기존 채널 비율을 따른다. 국문·영문 문장 길이, 제목 위치, 텍스트 안전영역, 출처·자산 이용권한, 대체 텍스트를 고려한다. 비율을 새로 정하거나 외부 폰트·브랜드·임의 사진을 설치하지 않는다.
4. **필요한 변형만.** 실제 요청된 채널에 한해 크롭·재배치로 무엇을 보존할지 적는다. 서로 의미 있는 방향이 있을 때만 소수 대안을 비교하고, 차이 없는 시안을 수량 목표 때문에 늘리지 않는다.
5. **완료 확인.** 카피 승인 후 기존 HTML 제작·렌더·QA를 거친다. 모바일에서 핵심 관계와 법률 조건이 읽히는지, 인접 카드와 구도가 불필요하게 반복되지 않는지 확인한다. 미감 평가는 권고이며 수치 점수로 발행을 자동 승인하지 않는다.

## 표지·대표 이미지 한정 보강

Canvas Design에서 참고한 것은 하나의 시각적 중심, 공간·대비·구성의 일관성, 마지막 시각 검수라는 방법이다. 이를 독자적으로 재구성해 표지·대표 이미지에만 적용한다. 원본의 최소문자 비율, 긴 미학 선언, 외부 폰트 묶음, PDF 의무 납품은 가져오지 않는다. 본문 카드의 법률 조건·예외·수치를 줄이거나 작은 장식 글자로 처리하지 않는다. 새 이미지 제작이 요청된 경우 사용 가능한 이미지 도구와 권한을 확인하며, 기획만 했을 때 이미지도 만들었다고 하지 않는다.

필요하면 고정된 `vendor/rampstack-skills/skills/art-direction/SKILL.md`와 해당 references에서 제작 브리프 항목만 참고한다. 원본의 예시 수치·비용 배수·유료 제작 일정·추가 스킬 호출을 사실이나 의무로 가져오지 않는다. 승인 원고·기존 시안은 별도 사용자 요청 없이 덮어쓰지 않는다. 비공개 자료 외부 전송·유료 API·실제 게시를 자동 실행하지 않는다.
