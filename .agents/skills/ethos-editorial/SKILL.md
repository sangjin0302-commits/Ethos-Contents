# ETHOS Editorial

먼저 해당 채널 명세와 실제 원고를 읽는다. 블로그는 `docs/blog-authoring-spec.md`, 파생 SNS는 `docs/sns-authoring-spec.md`, 웹사이트는 `docs/website-md-spec.md`를 따른다. 공통 경계와 출처는 `docs/writing-design-skills.md`에 있다.

## 적용 시점

새 글은 독자·질문·검증된 근거를 정한 뒤 자연스럽게 초안을 쓴다. 초안부터 점수표와 고정 목차를 강제하지 않는다. 기존 글은 사용자가 요청한 편집 범위와 앞뒤 문맥을 확인한다. 전체 흐름 요청일 때만 원고 전체를 먼저 읽고, 읽지 못한 구간은 검토했다고 하지 않는다.

1. **보존할 부분부터 찾는다.** 좋은 도입·사례·핵심 질문·이미 승인한 제목·문체를 짚고 불필요하게 다시 쓰지 않는다. Source Lock: 승인 원문의 주체·대상·의무/재량·조건·예외·숫자·기한·인용·서비스 범위는 고정한다.
2. **구체적인 결함을 찾는다.** 답이 늦게 나오는 부분, 소제목만 나열된 부분, 실질적으로 반복하는 설명, 근거와 결론 사이에 빠진 조건, 도입 질문과 연결되지 않는 결말을 원문의 위치로 특정한다. 일반적인 마케팅 취향은 오류로 취급하지 않는다.
3. **구조 → 내용 → 문체 순으로 필요한 부분만 고친다.** 독자의 질문이 발전하는 순서로 문단을 연결한다. 설명을 줄이더라도 법률 조건·예외·문서 대조·유용한 사례는 삭제하지 않는다. 글자 수를 맞추기 위한 축약·증량이나 전체 자동 재작성은 하지 않는다.
4. **도입부와 문단 피드백을 제한적으로 보강한다.** 기존 도입이 약할 때만 같은 근거로 1~2개 대안을 비교한다. 문단별로 핵심 주장·근거·다음 문단과의 연결을 확인한다. 새로운 수치·가상 전문가 인용·수임 경험·성과를 만들어 흥미를 높이지 않는다. 외부 스킬의 예시 숫자·인용은 근거가 아니다.
5. **결말과 채널 형식을 유지한다.** 도입의 질문을 회수하고 실제 자료와 다음 행동을 연결하되, 네이버의 기존 무료 검토 안내·상담 이미지 영역·3줄 요약·태그 순서를 지킨다. 리멤버 등 직접 영업 CTA가 허용되지 않는 채널에는 추가하지 않는다. 웹사이트 frontmatter와 제목 규칙을 임의 변경하지 않는다.
6. **의미를 재확인한다.** `docs/language-quality-workflow.md`에 따라 변경 문장과 영향을 받는 요약·결론을 원문과 대조한다. 표현이 좋아도 법률 의미가 달라지면 되돌린다. 실제 미확인 사실은 보류 표시하고 `docs/evidence-gate.md` 경로로 돌린다.

## 검색 의도·문제 해결 보완

새 블로그·홈페이지 원문과 관련 편집에서는 독자 질문에 대한 직접 답, 근거 있는 비교·문서 대조, 기존 글보다 추가로 해결하는 판단, 다음 행동이 이어지는지 기존 검수 안에서 살핀다. 필요하면 `docs/search-intent-writing.md`를 읽는다. 고정 목차·글자 수·새 점수 게이트로 바꾸지 않는다.

실제 검색 결과를 읽었을 때만 상위 글 분석이라고 기록하고, 타인의 매출·전환율은 자료 없이 추정하지 않는다. ETHOS는 광고 단가보다 업무범위에 맞는 적합 문의를 우선한다. '상위 1%' 역할 지시나 AI 문체 점수로 수익·순위·저품질 등급을 보장하거나 판정하지 않는다. 승인 원문의 파생·번역에는 새 사실을 보태지 않으며 채널별 CTA와 의미 재검증을 유지한다.

## 결과와 종료

승인본은 덮어쓰지 않고 별도 초안에 저장한다. 블로그의 최종 파일은 기존 TXT·MD 명세대로 만든다. 기존 작업 메모에 바꾼 위치·이유·보존한 조건·실제 검증 범위만 짧게 남긴다. 별도 필수 점수표·JSON 필드·새 승인 단계를 만들지 않는다. 실제 결함이 해소되면 멈추며 더 높은 문체 점수를 위한 반복 실행은 하지 않는다.

기본 편집은 이 ETHOS 절차만으로 수행한다. 원본 상세 체크리스트가 필요할 때만 고정된 `vendor/rampstack-skills/skills/content-and-copy/SKILL.md`와 그 상대경로의 references를 읽는다. 미초기화 상태에서 원본을 읽거나 실행했다고 하지 않는다. 원본의 타 스킬 자동 연쇄 호출·고정 SEO 길이·새 브랜드 정의·CMS 발행 기본값은 가져오지 않는다. 비공개 자료의 외부 전송·유료 호출·발행은 이 스킬로 승인되지 않는다.
