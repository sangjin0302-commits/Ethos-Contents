## 자동 검사와 실제 디자인의 구분

- qa_render.py: PASS. 쉼 카드 6의 3줄 큰 제목과 하단 77px 여백은 권고값을 넘지만 실제 이미지에서는 의도한 쉼과 한 문장 읽기가 유지된다.
- design_review.py: 자동 초안 표시, keyword 시각 중심 반복, 2~3 및 7~8의 비교형 구도 반복 권고. 미리보기에서 자료·조건을 비교하는 기능은 유지된다. 최종 자유 디자인 완성으로 기록하지 않는다.
- 자동 미리보기는 현재 저장소 프레임의 우측 하단 쪽수와 진행바를 출력한다. 제작 명세의 발행용 쪽수 비표시 방향과 차이가 있어, 승인 후 해당 콘텐츠 HTML에서 최종 조정할 항목이다. 공통 프레임을 임의 수정하지 않았다.
- 표지의 큰 문서 그림은 자동 렌더가 첫 art만 사용한 결과다. 상자·용기·상세페이지를 모두 그린 최종 표지라고 주장하지 않는다. 제목의 ‘인쇄 전’, 7번 ‘기미 치료’가 자동 줄바꿈에서 분리되므로 승인 후 의미 단위 조정 권고.
- copy_lint.py: 원문 blog.md의 ‘따라서’ 반복 경고는 읽기 전용 원문이므로 유지. 카드 7의 ‘범위에서’는 법률 조건을 보존하려고 유지. 질문형 비율·다른 세트와 같은 문서 아이콘·lead-magnet 부재는 비차단 안내다.
- validate_distribution.py와 marketing_review.py의 전체 CLI는 card-data.en.json이 없어서 완료되지 않는다. 이는 이번 사용자의 국문 전용 요청과 도구의 양언어 전제 차이이며, PASS로 숨기지 않았다. 원본 검사 코드는 수정하지 않았다. verify-preview.py에서 같은 도구 함수로 국문 대체텍스트 1~10과 자산 기록을 검증하고, 국문 마케팅 권고를 별도 기록했다. 영어 파일을 허위로 만들어 검사에 통과시키지 않았다.
- 자동 점수는 문의·수임 성과나 법률 적합성을 증명하지 않는다.

## 재현

저장소 루트의 Git Bash에서 PYTHON=python, PYTHONUTF8=1을 설정한다. 저장소 지정 playwright 1.63.0, Pillow 12.1.0, jsonschema 4.26.0을 사용했다. 이 작업은 로컬 Chrome을 CHROMIUM_PATH로 지정했다.

1. `python content/COSMETICS-LABEL-07-CARD-DRAFT/prepare-records.py`
2. `python content/COSMETICS-LABEL-07-CARD-DRAFT/render-preview.py`
3. `python content/COSMETICS-LABEL-07-CARD-DRAFT/verify-preview.py`
