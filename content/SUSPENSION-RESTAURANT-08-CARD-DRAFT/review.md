# 검토 기록

## 상태

- 사용자 제공 원고와 JSON을 기준으로 제작한 국문 비발행 미리보기
- 사용자 발행 승인 전이며 승인 완료로 기록하지 않음
- 이전에 잘못 전달된 화장품 원고와 산출물은 이번 Source Lock에 사용하지 않음

- 국민권익위원회 서행심 2009-21(2009. 4. 6.): 기소유예를 반영해 이미 2개월을 1개월로 감경한 처분을 유지
  - https://law.go.kr/LSW/deccInfoP.do?deccSeq=144629
- 2024. 4. 19. 식품위생법 시행규칙 개정: 1차 7일, 2차 1개월, 3차 2개월 및 과징금 전환 개선
  - https://www.law.go.kr/LSW/nwRvsLsInfoR.do?lsiSeq=261945

## QA

- 렌더 QA 10/10 PASS
- 영문 렌더 QA 10/10 PASS
- 축소 시트 전체 육안 확인: 글자 잘림·겹침·소실 없음
- 영문 축소 시트 전체 육안 확인: 글자 잘림·겹침·소실 없음
- 카드 7은 의도적으로 여백이 넓은 쉼 카드이며, 자동 QA의 여백 권고를 확인하고 유지
- 표지의 4개 정보 블록은 질문·두 결과·핵심 판단으로 역할이 구분되어 실제 가독성 확인 후 유지
- JPEG 10개는 1080×1350 RGB로 별도 검증
- 영문 JPEG 10개도 1080×1350 RGB로 별도 검증

## 영문 현지화

- `행정사사무소`는 프로젝트 기준에 따라 `Administrative Attorney Office`로 표기했다.
- 표지와 카드 7은 영문 길이로 인한 넘침을 해소하기 위해 문장을 압축했으며, 두 재결의 숫자와 반복위반 판단 의미는 그대로 유지했다.
- `처분 면제`, 재량적 `감경`, `과징금 전환`을 서로 다른 법적 효과로 유지했다.

## 의미 보존

- 과거 두 재결례의 처분기간을 현행 기준으로 오인하지 않도록 카드 3에서 명시적으로 구분했다.
- 처분 면제, 감경, 과징금 전환을 서로 다른 판단 단계로 유지했다.
- 기소유예를 자동 감경으로 단정하지 않았다.
- 과거 사건 결과가 다른 사건의 동일 결과를 보장한다는 표현을 넣지 않았다.
