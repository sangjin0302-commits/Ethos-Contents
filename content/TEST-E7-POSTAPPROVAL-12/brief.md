# E-7 비자 ⑫ — 국문 카드뉴스 브리프
독자: 이미 E-7 인력을 고용한 기업의 대표자·인사담당자
질문: 연봉·실제 직무·근무지가 달라져도 계약서만 바꾸면 되는가?
직접 답: 각각 임금기준·허용 활동범위·근무처 절차를 별도로 판단해야 하며 일부 변경은 신고 대상이 아니다.
CTA 자료: 기존 E-7 허가내용, 고용계약서, 변경안과 실제 적용일
CTA 확인 결과: 우선 확인할 임금요건·출입국 절차·추가 자료 (유료 서면검토·작성·제출은 별도)
카드 1~5: 계약서만으로 충분한가 → 예정/이미 변경 → 세 기준 → 임금 막대 비교 → 15일 신고 구분
카드 6~10: 핵심 쉼 문장 → 부서명/업무 구분 → 세 근무지 유형 → 준비자료 → 무료 초기 검토
OMITTED: 개별 E-7 직종별 고시상 신고 예외의 확정 판정, 판례·고충민원 상세내용
상태: 국문 비교용 초안, 원문 기준으로 QA 및 사용자 승인 전
