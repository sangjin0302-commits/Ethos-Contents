# 사전통지서 확인표 — 영업정지를 과징금으로 바꿀 수 있을까

에토스 행정사사무소 · 「사업이 멈추는 행정처분」 제4편 받을 자료. 원문(`blog.md`)에 있는 내용만 한 장으로 정리했다. 개별 사건의 결론이 아니다.

## 1. 사전통지서에서 먼저 표시할 것
- [ ] 의견제출기한 — 사전통지서에 적혀 있다(행정절차법 제21조 제1항 제6호). 10일 이상으로 정하도록 되어 있다(같은 조 제3항)
- [ ] 적용 법률과 위반조항
- [ ] 위반차수(처음인지, 반복인지)
- [ ] 예정된 영업정지 기간

## 2. 미리 모아 둘 자료
- [ ] 사전통지서
- [ ] 과거 처분서
- [ ] 매출 자료, 거래처 자료

## 3. 과징금 전환, 네 가지 순서로 보기
1. **근거** — 근거법률에 영업정지를 갈음하는 과징금 규정이 있는가
2. **제외** — 이번 위반행위와 위반차수가 제외대상인가
3. **전력** — 과거 위반·과징금 처분이 다시 전환을 막는가
4. **실익** — 예상 과징금과 영업정지 때의 실제 손실을 비교했는가

## 4. 전환이 막히는 경우
- [ ] 처분조항 자체에 영업정지를 갈음하는 과징금 근거가 없다
- [ ] 이번 위반행위나 위반차수가 법령상 제외대상이다
- [ ] 과거 과징금 처분 등으로 일정 기간 다시 전환할 수 없다
- [ ] 사업 손실만 주장하고 법이 정한 전환요건을 입증하지 못했다

## 5. 알아 둘 것
- 행정심판 재결이 나오면 같은 처분으로 다시 청구할 수 없다(행정심판법 제51조). 무엇을 요구할지(취소·감경·과징금 전환)는 첫 청구에서 정한다.

---
제외대상인지, 반복위반이나 과거 처분으로 막히는지, 어떤 대응을 요구할지는 개별 검토가 필요하다. 의견제출기한 전에 사전통지서와 과거 처분서로 무료 검토를 받을 수 있다.
