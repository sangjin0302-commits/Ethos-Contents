# OEM 영문 CARD-FLOW 검수
상태: 별도 초안, 사용자 승인 대기. 커밋·푸시 없음.

## 변경
국문 CARD-FLOW의 10장 순서와 역할을 영문에 적용했다. 2번은 제조/판매 역할을 전폭 두 행으로, 4번은 납품과 시험결과의 제조번호 대조로, 7번은 원칙과 두 예외로, 9번은 세 문서의 예시 문구 비교로 구성했다.
단어별 직역 대신 영어 질문·행동 문장으로 현지화했다. 이모지는 장식보다 문서·제조·변경·검토의 구분에 사용한다. 본문은 21 CSS px 이상, 자동 축소 없이 렌더한다. 영단어 자동 하이픈은 비활성화했다.
기존 승인 원고, 최신 국문 원고/카드, 이전 영문, 공통 지침은 수정하지 않았다.

## 검증
- 영문 렌더 QA 10/10 PASS. 모든 JSON 표시 문구가 렌더 텍스트에 포함됨.
- 동일 Chromium, 540×675 CSS px, DPR 2로 전후 영문 20장 렌더. 산출 PNG 1080×1350.
- 국문 원본/복제본 20장 렌더, 10쌍 픽셀 동일.
- 기존 OEM 파일 313개 SHA-256 일치.
- 법령 제6·11·12조와 국문 조건 대조: legal-parity.md 및 원문 응답 참조.
- 별도 에이전트가 영문 전체와 개별 렌더를 교차 검수. localization-review.md 참조.
- 구조 검증은 validate_bilingual.py, 화면 검증은 qa_render.py 및 compare.py로 재현한다.

## 한계와 검토 포인트
7번은 예외 조건을 같은 카드에 보존해 글이 많다. 6·8·10번도 글자/단어 수 권고를 넘으며 9번 설명은 5줄이다. PASS는 넘침·구조 검증 결과이며 읽기 성과나 마케팅 성과를 증명하지 않는다. 문장 축약을 이유로 주체·AND/OR·재량·범위를 삭제하지 않았다.
기존 영문과 최신 국문은 일부 구성이 달라, 전체 개선을 순수 레이아웃 효과로 수치화하지 않는다.

## 결과
comparison/index.html에서 전후 10장과 각 장 국문·영문 문구를 함께 확인한다. 2·4·7·8·9·10번은 별도 좌우 비교 PNG도 제공한다. 새 초안의 수용 여부는 사용자가 결정하며, 이번 작업에 발행·원본 교체·공통 규칙 변경은 포함하지 않는다.
