# 사용자 채택 기록

2026-10-25: 사용자가 “좋아 이 영문 버전으로 가자”라고 채택하고, 공통 지침·인수인계 반영 및 테스트·원격 CI 확인 후 커밋·푸시·머지를 요청했다.

범위: 별도 EN-FLOW 영문 10장과 문장·배치 원칙의 향후 적용. 기존 승인 원고와 법률 조건은 유지한다. 실제 SNS 공개 발행은 수행하지 않았다.

review.md와 comparison/index.html의 승인 전·커밋 없음 문구는 비교 제작 당시 상태다. 이후 상태는 이 파일과 PR 이력으로 확인한다.

## 반영 전 검증

- 지침 경로 검사 46개 PASS, 양언어 구조 PASS.
- 회귀 테스트 211개 PASS. 초기 제한 환경 실행 오류 후 자식 프로세스 실행이 가능한 환경에서 재실행했다.
- CI와 동일한 ci_render.py 경로: 국문 10장·영문 10장 QA PASS, 대표 이미지 2장 PASS. 밀도·유형 반복 등 편집 권고는 유지한다.
- 기존 OEM 파일 313개 SHA-256 일치. 기존 승인 원고·법률 문구 변경 없음.
- 원격 CI와 병합 결과는 연결된 PR의 정확한 커밋을 기준으로 확인한다.
