# 사업이 멈추는 행정처분 ⑧ — 역할·독자 여정·전환 설계

- 확인 대상 원고: `content/SUSPENSION-RESTAURANT-08-REALCASE-DRAFT/blog.md`
- 확인한 정본: `docs/blog-authoring-spec.md`, `docs/content-architecture-system.md`, `docs/topic-log-integration.md`
- 글감관리표 기준: 프로젝트 제공 `에토스_글감관리표` 인덱스(2026-10-12~13 상품 상태 기록); 신규 실제 발행 URL/글별 문의 성과는 확인되지 않음
- 유형: 이미 작성한 제8편의 마케팅 강화·독자 적용 보완 / 신규 판매 글 아님

## 작성 전 역할표 — 7항목

1. **주 독자**: 일반음식점 영업정지 사전통지를 받고 기소유예·신분증 도용·감경 사유 중 무엇을 먼저 확인할지 고민하는 음식점 영업자. 소비기한 경과 식재료 적발 영업자도 부차 독자. 최종 처분 후 불복절차만 궁금한 독자는 ⑫ 등 별도 콘텐츠가 더 적합.
2. **실제 질문/검색 표현**: 일반음식점 영업정지 감경, 청소년 주류 제공 영업정지, 미성년자 술 판매 신분증 도용 처분 면제, 기소유예 영업정지, 소비기한 경과 음식점 영업정지. 검색량·순위는 미확인.
3. **콘텐츠 주 역할**: **Authority**(실제 재결의 판단 기준과 서류 대조 능력 증명). Traffic·Revenue 요소는 보조. 판매 안내 반복 금지.
4. **독자 여정 위치**: **신뢰**(검색 발견 → 사실·법령 이해 → 재결례를 통해 판단 차이 신뢰 → 접수 여부 결정). 이 글을 읽고 당장 의뢰하지 않는 독자에게도 실제 자료 확인법을 남긴다.
5. **직접 답 1문장**: 같은 청소년 주류 제공 사건이라도 위반사실의 인정, 면제·감경사유의 확인, 이미 처분에 반영된 사정 및 현행 적용 기준이 달라 처분 결과가 달라진다.
6. **다음에 연결할 콘텐츠/자료 하나**: **기존 공개 서비스 `ETH-S45 영업정지 사전통지·의견제출 자료점검`**의 안내/접수 동선. 프로젝트 글감관리표에 공개상품으로 기재되어 있지만 이 미발행 8편의 개별 `package_id` 연결 승인/실제 발행 URL은 미확인; 발행용 접수 이미지에는 상품 ID를 임의로 붙이지 않음. 신규 상품 ID/독립 판매용 글 제작 금지.
7. **Primary Objective + CTA 한 개**: 적격 음식점 사업자의 **무료 사전 검토 접수**(실제 사전통지서를 받은 대상의 유효문의). 후반부에만 1회. 문서별 구체 검토·의견서 작성·허용 제출은 유료 범위로 구분.

## 독자 여정 내 글의 임무

| 단계 | 독자 질문 | 이번 원고의 대응 | 다음 행동 |
|---|---|---|---|
| 발견 | '우리 식당도 처분을 줄일 수 있나?' | 부산 2개월→15일 / 서울 1개월 유지의 실제 대조로 관심 확보 | 글 읽기 |
| 이해 | '왜 기소유예를 받아도 결과가 다르나?' | 위반사실과 처분기간의 판단, 이미 반영한 사정 구분 | 자기 처분서의 적용 기준 확인 |
| 신뢰(주 역할) | '이 사건에서 어떤 자료를 봤나?' | 재결기관이 인정한 사실과 당사자 주장을 분리하고 통지서·CCTV·기소유예 결과·전력 대조 설명 | 실제 자료 확보 |
| 결정(연결) | '어디까지 직접 하고 무엇을 의뢰하나?' | 무료 방향 안내와 유료 서류 작성·제출 범위 구분, 기존 ETH-S45 경로 연결 | 후반 온라인 접수 1회 |

## 이번 수정에서 적용한 전략

- 제목과 실제 부산·서울 재결례는 유지. 두 재결에서 어느 단계에 이미 감경이 반영됐는지 도입부터 제시하여 사례 감경결과만으로 성과를 과장하지 않음.
- 실제 사건의 주장은 주장으로, 재결기관이 인정한 사실은 사실로 명시. 이 사건은 에토스 수임·성과가 아니라 공개 재결례.
- 본문 2절 뒤에 독자가 과거 처분서·사전통지서를 직접 대조할 기준 추가.
- 9절을 **사전통지서 대 적발기록 / 신분증 확인 자료 / 기소유예·이전 처분기록** 중심으로 재정리해 증거와 법정 면제·감경 경계를 구체화.
- 결론부에서 직접 확인할 항목과, 별도 유료 작성·제출 업무에서 정리하는 내용을 구분.
- CTA에서 받을 자료 3범주와 무료 안내 결과를 명시. 독립적인 무료 서류감정·형사대리·행정심판/소송 대리·처분 변경 보장 없음.
- 시리즈 ①(일반 사전통지), ④(업종 횡단 과징금), ⑪(반복위반), ⑫(처분 후)와 구별: 제8편의 유일한 중심 질문은 **같은 일반음식점 위반이 실제로 왜 다르게 끝났는가**.

## 성과 해석과 검증 경계

- 현 시트의 ETH-S45는 기존 공개 서비스로 표시되나, 제8편의 글별 실측 검색량·조회수·유효문의·계약 건수는 확인되지 않음. 특정 콘텐츠 역할의 예상 매출/전환율을 숫자로 단정하지 않음.
- 발행 확인 후 기존 콘텐츠 ID·K열 네이버 실제 발행 URL·승인된 상품 연결을 기존 기록과 대조. 미확인 `package_id`·추적 URL은 원고에 작성하지 않음.
- 발행 후 실제 조회 → 링크 클릭/접수 → 업무범위 내 유효문의 → 유료 서면작성/제출 계약 단계의 측정 가능 범위만 평가. 조회수만으로 수임 성과 추정 금지.
- 후속 개선은 동일 주제의 콘텐츠 묶음과 최근 90일 관찰 후 실제 병목(조회는 있으나 적격문의 없음, 문의는 있으나 수임 없음 등)에 맞춰 수행.
