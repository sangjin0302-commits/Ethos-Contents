# OEM 시각 개선 초안 — 법률 조건 보존

검토일: 2026-10-25 KST. 편집·검수 기록이며 개별 사건 자문이나 발행 승인이 아니다.

## 확인한 1차 자료

한국법 MCP search_law와 get_batch_articles로 확인했다. MST 291337·285249 배치 조회는 실패했으므로 성공으로 기록하지 않는다. 법령ID로 재조회하여 다음 조문 전문을 실제 읽었다.

- [화장품법](https://www.law.go.kr/법령/화장품법) 제5조. 검색 판본 MST 291337, 공포 2026-10-20.
- [화장품법 시행규칙](https://www.law.go.kr/법령/화장품법시행규칙) 제6·11·12조. 검색 판본 MST 285249, 공포 2026-03-31. 직전 감사에서 확인한 판본과 검색 식별자가 같다.
- [행정사법](https://www.law.go.kr/법령/행정사법) 제2조. 법령ID 001025로 조문 전문 확인.

이번에는 법령 조문을 확인했다. 판례·행정해석을 새로 채택하지 않았고, 보고 관련 고시·별표 전문을 재검증하지 않았다. 기존 블로그의 해당 설명을 수정하거나 새 보고기한·절차를 추가하지 않았다.

## 의미 대조

| 조건 | 최종 초안의 보존 위치와 판단 |
|---|---|
| 국내 OEM·책임판매업자 범위 | 블로그 도입, 카드 1의 국내 OEM 문구. 수입·모든 판매자에 일반화하지 않음 |
| 제조업자와 책임판매업자 의무 | 블로그 관련 법률 문단 유지. 카드 2 카피 그대로 |
| 검사 생략 가능: 동일사업자 OR 적격기관 위탁 AND 제조번호별 결과 | 카드 3 카피 그대로. ‘하지 않을 수’ 유지. 단순 검사위탁만으로 자동 면제로 쓰지 않음 |
| 제6조제2항제2호 기관 범위 | 카드 3의 법정 요건을 갖춘 기관 등 한정 유지. 원문의 구체 기관 예시는 블로그에 유지 |
| 제12조제6호의 관리·감독, 기록 수령·유지·관리, 최종품질관리 | 기존 카드 4 상세 반복을 덜고 카드 2·3·4 결론에 보존. 이 글의 제조 위탁 범위에서 설명 |
| 제조번호별 결과와 기록 확인 | 새 카드 4가 상자/검사자료 대조를 구체화. 카드 5는 자료 수령과 적합 판정을 구분 |
| 제출 원칙 및 예외 | 카드 7에 필요한 사항 제출, 동일사업자 예외, 별개사업자 누적조건을 모두 제시. 필요한 사항을 모든 제조자료로 확대하지 않음 |
| 설계·개발·생산 AND 품질·안전 영향 없는 범위 AND 상호 계약상 영업비밀 | 카드 7 요약과 카드 8 세 행에 모두 보존. ‘모두’, ‘범위’, ‘제출하지 않을 수’ 유지. 아이콘이 조건을 대체하지 않음 |
| 일괄 비공개 금지 | 카드 8 결론 유지. 블로그의 모든 처방 요구와 법정 필요 자료의 구분도 유지 |
| CGMP와 의무 분리 | 블로그 법률 문단 불변. 카드에는 이전과 같이 상세 설명을 넣지 않음 |
| 고객 불편·보고·안전조치·비용분담 구분 | 해당 블로그 문단 불변. 카드 9 note에 판매 후 문의의 협의/자료 담당자 유지. 고시 세부기한 추가 없음 |
| 변경 통보·서면확인은 계약상 약정 | 카드 6 카피 그대로. ‘약정할 수’와 변경별 추가시험 판단 유지 |
| 검사 불일치 및 납품 일정 대응 | 블로그 문단 불변. 카드 9 note의 협의·자료 담당자 확인 유지. 조치 의무를 새로 단정하지 않음 |
| 행정사 업무범위 | 블로그 제2조 관련 문단에서 ‘관련해서도’만 자연스럽게 수정. 다른 법률 제한, 기술 판정·보증·분쟁·소송 경계 보존 |
| 무료 사전 검토와 유료 작성 | 블로그 CTA와 카드 10 모두 기존 자료·결과 범위. ‘지금 가진 자료’는 기존 ‘현재 보유’ 의미이며 무자료 검토·새 서비스 약속 없음 |

카드 9 문서 문구는 승인 원문의 설명용 예시를 옮겼다. 실제 고객 서류·법정 표준조항으로 표시하지 않고 ‘원문의 예시’라고 명시했다. 4번의 제조번호는 새 번호를 만들어 넣지 않고 확인 위치와 행위를 표현했다.

## 기계 대조와 사람 판단의 경계

승인 원본+직전 비교본 124개 파일 SHA-256을 보존했다. 블로그 숫자 토큰·직접 인용의 순서와 내용 일치, 법령명/조문 포함 10문단 대조를 수행했다. 행정사 문단의 문체 수정 1곳만 별도로 허용했다. 카드의 AND/OR·의무/가능·적용 주체는 위 표처럼 문장을 읽어 대조했다. 단어 일치나 렌더 PASS만으로 법률 정확성을 인증하지 않는다.
