# content/

콘텐츠 1편 = 폴더 1개. `content/_TEMPLATE/` 를 복사해 `content/<CONTENT_ID>/` 를 만든다.

```
content/GAME-KR-06/
  blog.md            승인된 원문 (사람이 넣는다)
  brief.md           각도·Hook·카드 계획 (에이전트 작성 → 사람 승인)
  card-data.json     카피 + Source Trace (승인 표시 후 렌더)
  card_01.html …     카드 HTML (에이전트)
  out/               png/, sheet-270.png, qa-report.md|json (qa 통과 시 생성)
```
