## 바꾼 점

2번은 좌우 두 열을 넓은 두 행으로 바꾸고 시험/기록, 감독/결과 관리를 각각 두 문장으로 나눴다. 본문 줄 수는 4·5줄에서 2·3줄로 줄었으며 글씨 22 CSS px를 유지했다.

7번은 제조업자가 제출한다는 주체를 명시하고, 압축된 예외 조건을 두 문장으로 풀었다. ‘별개 사업자: 세 조건 모두’와 ‘법정 예외에 해당하는 범위에서 제출하지 않을 수 있습니다’를 함께 남겼다. 8번은 설계·개발·생산과 상호 계약 조건을 완결된 설명으로 바꿨다. 9번은 원문 문서 인용 3개를 그대로 두고, 사양 변경·검사 불일치·판매 후 문의에서 누구와 협의하고 누가 자료를 맡는지 풀어 썼다.

## 같은 기준 재평가

docs/card-evaluation-rubric.md의 기존 1~5점, 가중치 2:2:1:1을 그대로 적용했다. 주 담당과 별도 문체 에이전트가 실제 이미지를 보고 같은 평가에 도달했다. 문체 에이전트도 윤문에 참여했으므로 블라인드 평가나 외부 법률 전문가의 승인으로 표현하지 않는다.

| 항목 | 이전 | 개선 |
|---|---:|---:|
| 표지·카피 ×2 | 3 | 4 |
| 가독성·일관성 ×2 | 4 | 4 |
| 흐름 ×1 | 4 | 4 |
| 사실·형식 ×1 | 5 | 5 |
| 가중 합계 | 23/30 | 25/30 |
| 100점 환산 | 76.7 (반올림 77) | 83.3 (반올림 83) |

정확 환산 차이는 약 +6.7점, 표시 점수는 77→83이다. 문장 자연스러움 개선만 C1에 반영했다. 7번은 여전히 조밀하므로 가독성까지 중복 가점하지 않았다. 실제 이해도·저장률·문의 전환율 개선은 측정하지 않았다.

## 측정·검증

- 승인 원본과 이전 OEM 초안 225파일 SHA-256 일치. 블로그 바이트 동일. 1·3·4·5·6·10번 JSON·HTML 그대로.
- [같은 Chromium 전후 20장 검사](comparison/browser-checks.json): 카피 전부 표시, 이미지 로딩 정상, 자동 축소 없음, 넘침 없음. 새 10장 1080×1350 PNG 생성 및 [렌더 QA PASS](out/ko/qa-report.md).
- 개별 비교 4개와 전체 시트를 실제 열어 여백·위계·조건 연결 확인. 비교 페이지 390px 가로 넘침 없음. 실제 휴대전화 앱 경험은 별도다.
- [공백 포함 JSON 카피](comparison/metrics.json): 2번 147→151자, 7번 201→235자, 8번 176→184자, 9번 157→183자. 네 장 합계 681→753자(+10.6%). 가운뎃점 11→5개. 문장으로 풀어 문량은 늘었다.
- humanize-korean 고정 버전 light 경로: 사전 진단 → 문체 에이전트 윤문 → 주 담당 법률 의미 대조·7번 보완 → 게이트. [최종 윤문](_workspace/2026-10-25-001-8436/final.md), [게이트](_workspace/2026-10-25-001-8436/gates.json). 변경률 9.4%, 서법 소실 0문장, exit 0. 장르·격식체·인용·의미 등 자체검토 6항, 보수 윤문 등급 B. 필요 시 Claude Code 정밀 경로로 추가 검토할 수 있다. 카드 QA·마케팅 점수와 다른 지표다.
- 카드 시스템 smoke 검사 PASS, 국문 JSON 스키마 PASS, 문서 인용 문자열 동일.
- copy_lint는 권고 1건(7번 라벨 길이), 본문 길이·법률 표현 등 정보 경고를 남겼다. 전후 보호 토큰 검사에서 ‘해야’ 2회 감소 경고는 ‘이어야/여야’로 표현한 필수 조건임을 직접 대조했다. [판정 근거](legal-review.md).
- validate_bilingual은 영문 파일 미존재로 FAIL. 이번 요청은 국문 4장 개선이므로 영문을 만들거나 양언어 완료로 표시하지 않았다. 국문 스키마는 별도로 통과했다.
- 디자인 반복 경고는 공통 visual-main 래퍼·concept 유형을 감지한다. 실제 7 원칙/예외, 8 조건 묶음, 9 문서 대조는 서로 다르다. 경고를 없애기 위해 조건을 삭제하거나 게이트를 완화하지 않았다.

## 남은 한계

7번은 QA 공백 제외 190자(권고 180자 초과)다. 설명을 풀어 쓰면서 원문 조건을 모두 남긴 결과이며, 22px 본문과 실제 넘침 검사 기준은 통과했다. 9번 설명도 긴 문장이다. 더 짧게 만들기보다 실제 모바일에서 이해하기 쉬운지 사용자 확인을 우선한다. 이번 국문 초안은 공통 지침·기존 승인본·영문·배포 패키지를 변경하지 않는다.
