New batch, or changed ingredients?

Batch only
If A001 and A002 differ only by batch number, and the reported ingredient list is unchanged, no new list report is needed.
Ingredients
If panthenol is added and the reported list changes, report the revised ingredients before that version is distributed or sold.
Compare the actual formula with the reported ingredient list, not just the batch number.
