# Brief
독자: 혼인신고 없이 함께 살 집을 구하고 보증금·생활비·공동구매 비용을 나누려는 커플.
질문: 동거계약서에 무엇을 적어야 하고, 사실혼·공증·상속과는 어떻게 구분해야 하나?
직접 답: 집, 돈, 공동구매, 종료 절차, 증명 방식을 나눠 적되 실제 생활과 임대차·사실혼 법리를 따로 확인한다.
CTA 받을 자료: 임대차계약서 / 큰 금액 입금내역 / 정리하고 싶은 항목 목록.
CTA 확인 결과: 문서화 순서 / 별도 계약으로 분리할 부분 / 사실혼·공증 추가 확인 지점.
카드 1~3: 5가지 확인 → 계약 효력의 한계 → 단순 동거와 사실혼 구분.
카드 4~6: 임대차 확인 순서 → 저장용 정산표 → 종료 절차.
카드 7~9: 쉼 결론 → 공증의 역할 → 준비 자료와 무료 검토.
OMITTED: 상속은 블로그에서 설명하고 카드는 계약 전 5가지 흐름에 집중.
