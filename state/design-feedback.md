# 디자인 피드백 기록

사용자가 카드 디자인·문구에 준 피드백을 **원문 그대로** 적고, 무엇을 바꿨는지 한 줄로 남긴다. 요약하거나 다듬지 않는다(Kanghyeop/card-news-simple-skill의 기록 방식). 새 세트를 디자인하기 전에 이 기록을 읽고, 같은 지적이 다시 나오지 않게 한다. 반영은 `templates/presets/ethos-*.css`와 `docs/card-design-guide.md`에 한다.

| 날짜 | 피드백 원문 | 반영 |
|---|---|---|
| 2026-10-06 | "빈칸이 너무 많네 카드에.... 이거 왜 그런거야" | 세로형 본문 자동 맞춤, 번호 칸 124px → 36px, 가이드 "빈칸을 글자로 채운다" |
| 2026-10-06 | "왜케 디자인에 빈칸이 많아 보이지... 그냥 클로드에 넣을때랑은 달라보이는데" | 자동 맞춤을 글자 크기 기준으로 변경, B 방식(카드마다 직접 디자인) 도입 |
| 2026-10-06 | "이번 카드는 왜케 제목이랑 내용이랑 다를 바가 없는거야" | 본문은 제목의 60% 이하, 글자 비율 3:1 규칙, 제목 38~44px |
| 2026-10-06 | "왜케 자연스럽지 않지... 원래 그런건가" | 메모체 금지(가운뎃점 나열), 가운뎃점 줄바꿈 보정, 표지 시리즈명 중복 제거 |
| 2026-10-06 | "너무 엄격하게 하지 않았으면 좋겠어. 이전에 너무 엄격하게 했더니 글이 안나오더라구" | 점검표를 권고로, 반드시 지킬 것 네 가지로 축소, 예시 우선 |
