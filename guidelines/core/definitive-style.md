# ETHOS 사실·조건·추론 문체 규칙 v1.0

> 적용일: 2026-10-04  
> 목적: 확인된 사실까지 습관적으로 흐리는 표현을 막고, 법률적 한정은 정확히 보존한다.

## 핵심 원칙

확인된 것은 단정한다. 조건이 있으면 조건을 먼저 밝힌 뒤 결론을 단정한다. 개별 사실관계·행정청의 재량·미확인 정보가 남아 있을 때만 유보한다.

## Evidence Label과 문체

- **F — 확인된 사실**: 공식 법령·고시·정부자료·공개 판결·재결 등으로 확인됐다면 `~합니다`, `~입니다`, `~해야 합니다`, `~할 수 없습니다`처럼 쓴다.
- **I — 분석·추론**: 근거와 추론을 구분하고 `~로 볼 수 있습니다`, `~일 가능성이 있습니다`처럼 한정한다.
- **S — 설명용 가상 상황**: 가상임을 명시한다. 실제 상담·수임·성공 사례처럼 쓰지 않는다.
- **U — 미확인 정보**: 발행하지 않는다. 먼저 확인하거나 삭제한다.

## 조건부 법리

조건을 숨긴 채 결론을 흐리지 않는다.

- 나쁨: `새 계약서가 필요할 수 있습니다.`
- 좋음: `기존 계약기간이 끝났다면 계속 고용관계를 확인할 수 있도록 계약을 갱신해야 합니다.`
- 좋음: `기존 계약이 유효하고 실제 근로조건과 일치한다면 새 계약서를 다시 작성할 필요는 없습니다.`

## 유보 표현을 허용하는 경우

1. 구체적 사실관계에 따라 결론이 달라지는 경우
2. 행정청의 재량판단이 필요한 경우
3. 예외규정의 적용 여부가 확정되지 않은 경우
4. 공식자료만으로 개별 사안의 결론을 확정할 수 없는 경우
5. 확인된 사실과 구분해 분석 또는 추론을 제시하는 경우

## 금지

- 사실을 확인했는데도 문장마다 `~할 수 있습니다`, `~일 수 있습니다`, `~가능성이 있습니다`를 붙이는 습관
- 허가·승인·승소 가능성을 보장하는 단정
- 조건·예외·절차를 삭제해 문장을 강하게 만드는 행위
- 마케팅을 이유로 법률상 의미를 넓히거나 좁히는 행위

이 문서는 `guidelines/core/master.md`의 과거 표현인 `단정 대신 여지`보다 우선한다.
