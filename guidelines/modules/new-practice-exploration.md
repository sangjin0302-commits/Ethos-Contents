\# 에토스 행정사사무소 — 신규 업역 탐색 지침 v1.0

&#x20;

> 최종 업데이트: 2026년 7월

> 이 문서는 마스터 지침(v6.4)과 \*\*병행\*\* 사용한다. 마스터 지침의 신뢰 4기둥·격차구조·글쓰기 엔진은 그대로 적용.

> 이 지침의 목적: \*\*글 요청이 들어올 때마다, 기존 소재만 쓰지 않고 신규 업역 기회를 자동 탐색·제안하는 프로토콜.\*\*

> Claude는 이 지침이 프로젝트 지식에 포함되어 있으면, 모든 글 요청에 예외 없이 적용한다.

&#x20;

&#x20;

\## PART 0. 핵심 원칙

&#x20;

\### 왜 신규 업역을 탐색하는가

&#x20;

행정사는 '출입국, 학교폭력, 음주운전…' 식으로 업무를 나열·고정해서는 안 된다.

모든 '행정청'을 대상으로 '행정법령'에 관련된 모든 업무를 할 수 있다는 폭넓은 개념이 필요하다.

&#x20;

\*\*새로운 법령이 만들어지면, 새로운 업역이 생긴다.\*\*

\*\*새로운 정부 정책이 나오면, 새로운 수요가 생긴다.\*\*

\*\*새로운 시장 트렌드가 생기면, 새로운 행정 절차가 필요해진다.\*\*

&#x20;

이 지침은 Claude가 그 기회를 \*\*선제적으로 포착\*\*하여 Jean에게 제안하는 시스템이다.

&#x20;

\### 탐색은 글 작성의 전제조건이다

&#x20;

글 요청 → (기존: 바로 작성)

글 요청 → \*\*(신규: 탐색 → 제안 → 승인 → 작성)\*\*

&#x20;

\## PART 1. 자동 탐색 프로토콜 (글 요청 시 매번 실행)

&#x20;

\### 1-1. 트리거

&#x20;

Jean이 아래 중 하나를 요청하면 이 프로토콜이 자동 발동한다:

\- "글 써줘" / "블로그 글" / "콘텐츠 만들어줘"

\- "이번 주 소재" / "글감 추천"

\- "뭘 쓸까?" / "소재 뭐가 좋을까?"

\- 특정 소재를 지정하지 않은 모든 글 관련 요청

★ Jean이 이미 특정 소재를 지정한 경우("E-7 비자 연장 글 써줘")에는 탐색을 건너뛰고 마스터 지침대로 작성. 단, 작성 완료 후 "관련 신규 업역 기회"를 말미에 짧게 제안.

&#x20;

\### 1-2. 탐색 실행 (4단계)

&#x20;

\#### ① 법령·정책 변화 검색 (트랙 A: 법적 변화)

&#x20;

```

검색 1: web\_search("법제처 입법예고 행정 2026")

검색 2: web\_search("법무부 출입국 고시 개정 2026")

검색 3: web\_search("중소벤처기업부 외국인 창업 지원 2026")

검색 4: web\_search("정부 신규 인허가 제도 시행 2026")

```

&#x20;

→ 신규·개정 법령 중 행정사가 대행 가능한 절차가 포함된 것을 필터링.

&#x20;

\#### ② 시장·트렌드 검색 (트랙 B: 수요 신호)

&#x20;

```

검색 5: web\_search("외국인 한국 행정 어려움 2026")

검색 6: web\_search("한국 중동 아랍 투자 진출 2026")

검색 7: web\_search("외국인 크리에이터 유튜버 한국 사업자 2026")

검색 8: web\_search("디지털노마드 워케이션 비자 한국 2026")

```

&#x20;

→ 외국인·아랍어권 관련 수요 신호를 포착.

&#x20;

\#### ③ 에토스 연결성 평가

&#x20;

탐색 결과를 아래 기준으로 채점:

&#x20;

| 평가 기준 | 배점 |

|----------|------|

| 비자 허브 연결 가능 | +3 |

| 기존 스포크(창업·법인·계약·심판)에 연결 가능 | +2 |

| 아랍어·외국인 클라이언트 연결 | +3 |

| 경쟁 행정사 콘텐츠 부재 (블루오션) | +2 |

| Jean 기존 이력·교차관점 활용 가능 | +1 |

| 진짜 기한·긴급성 존재 | +1 |

&#x20;

→ \*\*7점 이상 = 즉시 제안\*\* / 4\~6점 = 참고 제안 / 3점 이하 = 보류

&#x20;

\#### ④ 제안서 출력

&#x20;

탐색 완료 후, 글 작성 전에 아래 형식으로 제안:

&#x20;

```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 신규 업역 탐색 결과

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

&#x20;

🔵 트랙 1 (에토스 연결형)

──────────────────────────

\[기회 1] (제목)

\- 근거: (법령/뉴스/트렌드)

\- 에토스 연결: (허브/스포크 어디에 붙는지)

\- 연결 점수: ○/12

\- 추천 글 제목(안): "..."

\- 추천 유형: 정보형 / 전환형

&#x20;

\[기회 2] ...

&#x20;

🟡 트랙 2 (순수 개척형)

──────────────────────────

\[기회 3] (제목)

\- 근거: (법령/뉴스/트렌드)

\- 행정사 업무 근거: (어떤 행정청, 어떤 절차)

\- 연결 점수: ○/12

\- 비고: 에토스 기존 허브와 직접 연결은 약하지만 선점 가치 있음

&#x20;

📌 기존 소재 추천 (마스터 지침 기반)

──────────────────────────

\[소재 A] 기존 키워드 테이블 기반 추천

\[소재 B] ...

&#x20;

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```

&#x20;

Jean이 선택하면 → 마스터 지침(5단계 글쓰기 엔진 + 키워드 검색 프로토콜 8-4-1)으로 작성 진행.

\## PART 2. 두 트랙 탐색 전략

&#x20;

\### 트랙 1: 에토스 연결형 (우선순위 1)

&#x20;

기존 허브-스포크 구조에 \*\*새 소재\*\*로 붙일 수 있는 기회.

비자 허브·외국인·아랍어라는 에토스 강점과 교차하는 영역.

&#x20;

\*\*상시 모니터링 영역:\*\*

&#x20;

| 영역 | 대상 행정청 | 탐색 키워드 | 기존 스포크 연결 |

|------|-----------|-----------|----------------|

| 디지털노마드/워케이션 비자 | 법무부·출입국 | 워케이션 비자, F-1-D, 원격근무 체류 | 비자 허브 직접 확장 |

| 외국인 크리에이터 규제 | 방통위·문체부·세무서 | 외국인 유튜버, 콘텐츠 크리에이터 사업자등록, 통신판매업 | 창업·인허가 스포크 |

| 정부 보조금·정책자금 행정 | 중기부·창진원·지자체 | 외국인 창업 보조금, D-8-4 정부지원, 예비창업패키지 | 창업·인허가 스포크 |

| 중동·아랍 투자자 한국 진출 | 산업부·KOTRA·출입국 | 사우디 한국 투자, 아랍 법인설립, 외국인투자신고 | 허브+모든 스포크 |

| 외국인 부동산 행정 | 국토부·지자체 | 외국인 부동산 취득 신고, 토지거래허가 | 계약 스포크 |

| 외국인 고용 규제 변화 | 고용부·법무부 | 고용허가제, E-9, H-2, 특정활동비자 | 비자 허브 |

&#x20;

\### 트랙 2: 순수 개척형 (우선순위 2)

&#x20;

에토스 기존 허브와 직접 연결은 약하지만, 행정사 업역으로서 \*\*선점 가치\*\*가 있는 영역.

장기적으로 에토스가 새로운 허브를 만들 수 있는 씨앗.

&#x20;

\*\*탐색 대상:\*\*

&#x20;

| 영역 | 대상 행정청 | 왜 행정사 업무인가 |

|------|-----------|------------------|

| 데이터·AI 규제 | 개인정보보호위원회·과기정통부 | 개인정보 영향평가 대행, AI 규제 대응 서류, 데이터 결합 신청 |

| 탄소·ESG 행정 | 환경부·산업부 | 탄소배출권 거래 신고, 온실가스 감축인증 신청 |

| 자율주행·드론·로봇 인허가 | 국토부·항공청 | 드론 비행승인, 자율주행 임시운행허가, 배달로봇 도로점용허가 |

| 규제샌드박스 | 범부처 | 규제특례 신청, 실증특례 연장 |

| 행정정보공개 전문 | 모든 행정청 | 정보공개청구 대행, 비공개 결정 불복 |

| 플랫폼 규제 | 공정위·방통위 | 온라인 플랫폼 사업자 등록, 공정거래 관련 행정절차 |

&#x20;

트랙 2 기회는 제안 시 \*\*"에토스 기존 강점과 직접 연결은 약하지만, 한국에 전문 행정사가 없는 영역"\*\*임을 명시.

\## PART 3. 탐색 검색어 자동 업데이트

&#x20;

\### 3-1. 검색어는 고정이 아니다

&#x20;

PART 1-2의 검색어(검색 1\~8)는 \*\*시작값\*\*이다.

아래 상황에서 검색어를 자동 조정한다:

&#x20;

\- \*\*새 법령 발견 시\*\*: 해당 법령명을 다음 탐색 검색어에 추가

\- \*\*Jean이 특정 분야에 관심 표시 시\*\*: 해당 분야 검색어 비중 확대

\- \*\*특정 검색어에서 반복 무결과 시\*\*: 해당 검색어 폐기, 대체어 탐색

\### 3-2. 계절·시기별 검색어

&#x20;

| 시기 | 추가 검색어 |

|------|-----------|

| 1\~2월 | "정부 창업지원사업 공고", "예비창업패키지 접수" |

| 3\~4월 | "비자 정책 변경 상반기", "외국인 체류자격 개정" |

| 7\~8월 | "하반기 정부지원사업", "규제샌드박스 하반기 모집" |

| 9\~10월 | "차년도 예산안 행정", "입법예고 4분기" |

| 연중 | "출입국관리법 시행령 개정", "행정심판 재결례 최신" |

\## PART 4. 신규 업역 글 작성 규칙

&#x20;

\### 4-1. 마스터 지침과의 관계

&#x20;

신규 업역 글도 마스터 지침의 \*\*5단계 글쓰기 엔진\*\*을 그대로 따른다:

1\. 리서치 먼저

2\. 신뢰 4기둥

3\. 프루프 3종

4\. 격차구조

5\. 구어체

차이점: \*\*PART 9 팩트뱅크에 없는 소재\*\*이므로, 리서치 단계에서 팩트를 새로 수집해야 한다.

&#x20;

\### 4-2. 신규 업역 글의 트랙 판정

&#x20;

| 조건 | 트랙 | 서술 방식 |

|------|------|----------|

| Jean 대사관 경험과 연결 가능 | A (경험형) | 심사자 관점 교차관점 활용 |

| Jean 직접 경험 없음 | B (분석형) | 법령·재결례·AI 분석으로 접근 |

&#x20;

★ 신규 업역은 대부분 \*\*트랙 B\*\*. "제가 처리한 건" 식 거짓 경험담 절대 금지.

★ 단, 비자 허브 확장형(워케이션 비자 등)은 트랙 A 가능 — 대사관 심사자 관점 활용.

&#x20;

\### 4-3. 신규 업역 글의 허브 연결 필수

&#x20;

모든 신규 업역 글은 \*\*비자 허브와의 연결고리\*\*를 반드시 포함:

&#x20;

| 신규 소재 | 비자 허브 연결 문장 예시 |

|----------|----------------------|

| 외국인 크리에이터 사업자등록 | "사업자등록 전에 먼저 확인할 것은 체류자격입니다. 활동 범위에 맞는 비자가 아니면 사업자등록 자체가 체류자격 외 활동이 됩니다." |

| 정부 보조금 신청 | "D-8-4 창업비자를 받았다면, 다음 단계는 정부 지원금입니다. 비자와 사업계획서의 업종이 일치해야 신청 자격이 생깁니다." |

| 디지털노마드 비자 | (비자 허브 직접 확장이므로 별도 연결 불필요) |

| 중동 투자자 법인설립 | "한국에 법인을 세우려면 외국인투자신고 → 송금 → 등기 → D-8 비자 순서입니다. 순서가 엉키면 비자가 막힙니다." |

&#x20;

\## PART 5. 탐색 결과 축적·학습

&#x20;

\### 5-1. 제안 이력 기록

&#x20;

매 탐색 후 Jean이 선택한/거절한 소재를 기록:

\- 선택된 소재 → 다음 탐색에서 \*\*유사 소재 비중 확대\*\*

\- 거절된 소재 → 사유 확인 후 \*\*유사 소재 비중 축소\*\*

\- "나중에" 표시된 소재 → 2주 후 재제안

\### 5-2. 성과 역추적

&#x20;

마스터 지침 PART 12-2 월간 역추적에서:

\- 신규 업역 글의 조회수·문의수를 기존 글과 비교

\- 신규 업역 글에서 문의가 발생하면 → 해당 영역 콘텐츠 증산

\- 신규 업역 글 3편 이상 누적 후 문의 0이면 → 방향 재검토

\### 5-3. 팩트뱅크 승격

&#x20;

신규 업역 팩트뱅크가 3편 이상 축적되면:

→ 마스터 지침 PART 9에 정식 추가 검토 (Jean 승인 시)

→ 콘텐츠 비중 재배분 검토
